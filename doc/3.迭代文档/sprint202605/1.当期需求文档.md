# sprint202605 当期需求文档

版本：v1.0

迭代定位：AI智能刷题基础闭环  
前置依赖：sprint202601、sprint202602、sprint202603、sprint202604

## 1. 当期目标

基于默认题库实现AI智能刷题的第一个可用闭环：开始刷题、展示题目、提交答案、基础规则评分、保存答题记录、展示结果和基础成长反馈。

本期不接入大模型、RAG、Qdrant 或 ai-service，评分采用可解释的本地规则，后续再替换或增强为 AI 评分。

### 2.2 本期不做

- 不接入 ai-service、LangChain、LangGraph、LlamaIndex。
- 不接入 Qdrant、Embedding、RAG 检索。
- 不做个人题库导入和编辑。
- 不做复杂徽章、连续学习天数、排行榜。
- 不做代码题自动执行。

## 3. 刷题流程

1. 登录用户进入AI智能刷题页面。
2. 点击“开始刷题”。
3. 后端选择一道默认题，创建刷题会话。
4. 前端展示题目内容、题型、难度、知识点。
5. 用户输入答案并提交。
6. 后端校验会话和题目归属，执行基础评分。
7. 后端保存答题记录并更新用户经验。
8. 前端展示得分、命中点、缺失点、问题、参考答案、改进建议和成长反馈。

## 5. 接口需求

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/v1/agent/practice/start` | 登录用户 | 开始刷题 |
| POST | `/api/v1/agent/practice/submit` | 登录用户 | 提交答案并评分 |
| GET | `/api/v1/answer-records/me` | 登录用户 | 我的答题记录 |
| GET | `/api/v1/growth/me` | 登录用户 | 我的基础成长信息 |

开始刷题请求可选参数：

```json
{
  "difficulty": "MEDIUM",
  "questionType": "SHORT_ANSWER",
  "knowledgePointIds": ["知识点ID占位符"]
}
```

提交答案请求：

```json
{
  "sessionId": "会话ID占位符",
  "questionId": "题目ID占位符",
  "userAnswer": "用户答案占位符",
  "durationSeconds": 180
}
```

## 6. 验收标准

- 游客访问AI智能刷题页面时看到登录引导。
- 登录用户可以开始刷题并看到题目。
- 用户提交答案后能看到结构化评分结果。
- 答题记录保存成功，刷新记录列表可以看到历史记录。
- 用户经验值随答题更新，个人中心或成长接口能看到变化。
- 同一用户不能提交不属于自己的会话。
- 本期不需要启动 AI 服务和 Qdrant。
