## 2. 前端页面和功能验收

### 2.1 AI智能刷题页面

验收步骤：

1. 使用已注册账号登录平台。
2. 点击左侧菜单“AI智能刷题”。
3. 可选选择难度、题型和知识点，点击“开始刷题”。
4. 输入答案后点击“提交答案”。

验收点：

- 页面展示题目标题、题目内容、题型、难度和知识点。
- 提交空答案时前端提示“请先输入答案”。
- 提交成功后展示得分、命中点、缺失点、问题提醒、参考答案、改进建议和成长反馈。
- 评分结果区域展示“评分结果仅供学习参考。”。
- 点击“再来一题”可以重新开始新的刷题会话。

### 2.2 我的答题记录和成长概览

验收步骤：

1. 完成一次刷题评分。
2. 进入右上角用户菜单中的“个人中心”。
3. 查看成长概览和我的答题记录。

验收点：

- 成长概览展示当前经验、累计答题、平均得分、等级和段位。
- 我的答题记录按时间倒序展示题目标题、得分、题型、难度、改进建议和答题耗时。
- 刷新页面后答题记录仍存在，说明后端已落库。

### 2.3 权限和边界场景

验收步骤：

1. 退出登录后访问“AI智能刷题”。
2. 使用接口工具不带 token 调用 `/api/v1/agent/practice/start`。
3. 登录用户开始刷题后，修改 sessionId 或 questionId 再提交。

验收点：

- 游客访问页面时看到“登录后即可使用该功能”。
- 未登录调用受保护接口返回 `AUTH_UNAUTHORIZED`。
- 提交不属于当前用户或不匹配题目的会话时返回明确错误。
- 同一会话重复提交时返回“该刷题会话已提交，请重新开始刷题”。

## 3. 接口联调验收

### 3.1 开始刷题

```http
POST /api/v1/agent/practice/start
Authorization: Bearer <access_token占位符>
Content-Type: application/json

{
  "difficulty": "MEDIUM",
  "questionType": "SHORT_ANSWER",
  "knowledgePointIds": []
}
```

预期：返回 `sessionId`、`questionId`、题目内容、题型、难度和知识点。

### 3.2 提交答案

```http
POST /api/v1/agent/practice/submit
Authorization: Bearer <access_token占位符>
Content-Type: application/json

{
  "sessionId": "会话ID占位符",
  "questionId": "题目ID占位符",
  "userAnswer": "RAG 会先检索外部知识，再把知识片段和问题一起交给大模型生成答案。",
  "durationSeconds": 60
}
```

预期：返回 0 - 100 分结构化评分，并生成答题记录。

### 3.3 查询记录和成长

```http
GET /api/v1/answer-records/me?pageNo=1&pageSize=10
Authorization: Bearer <access_token占位符>

GET /api/v1/growth/me
Authorization: Bearer <access_token占位符>
```

预期：只返回当前登录用户自己的答题记录和成长信息。
