# sprint202609 当期需求文档

版本：v1.0  
日期：2026-05-14  
迭代定位：智能推荐与薄弱点分析  
前置依赖：sprint202601 - sprint202608

## 1. 当期目标

基于答题记录、个人题库、默认题库和 RAG 检索结果，升级刷题推荐能力，并在个人中心展示薄弱知识点和复习建议。

## 2. 当期范围

| 编号 | 需求项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| S09-R01 | 推荐权重规则 | 实现未刷、低分、薄弱点、个人题库和重复惩罚权重 | P0 |
| S09-R02 | 薄弱点分析 | 按知识点统计答题次数、平均分、低分次数 | P0 |
| S09-R03 | RAG 辅助推荐 | 无合适题目时尝试从 RAG 片段生成候选题 | P1 |
| S09-R04 | 复习建议 | 个人中心展示薄弱知识点和建议复刷题 | P0 |
| S09-R05 | 推荐解释 | 开始刷题返回本次推荐原因 | P1 |

## 3. 接口需求

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/v1/agent/practice/start` | 登录用户 | 响应增加 recommendReason |
| GET | `/api/v1/learning-analysis/me` | 登录用户 | 我的薄弱点和复习建议 |

## 4. 验收标准

- 低分题和薄弱知识点题目在推荐中更容易出现。
- 近期高分且频繁刷过的题目权重降低。
- 个人中心能展示薄弱知识点、平均分和建议复习题。
- 推荐逻辑具备可解释文案，便于用户理解为什么推荐这道题。
