## 1. 推荐公式

```text
题目权重 = 基础权重 + 未刷加权 + 低分加权 + 薄弱知识点加权 + 个人题库加权 - 高频重复惩罚
```

## 2. 后端设计

新增模块：

```text
com.earth.online.player.ailearn.analysis
com.earth.online.player.ailearn.agent.domain.QuestionRecommendationDomainService
```

关键规则：

- 未刷题：+30。
- 最近最低分低于 60：+25。
- 知识点平均分低于 70：+20。
- 个人题库：+10。
- 近 7 天高分通过：-20。

## 3. 数据设计

优先通过现有 `answer_records`、`questions`、`question_knowledge_points` 聚合查询。若性能不足，再新增用户知识点统计表。

## 4. 前端设计

- 刷题页面显示“推荐原因”。
- 个人中心新增“薄弱点分析”卡片。
- 支持点击薄弱知识点后跳转到 AI智能刷题并带入筛选条件。

## 5. 验证要求

- 构造低分答题记录后，同知识点题目推荐权重提升。
- 高分重复刷过的题目短期内不优先推荐。
- 用户只能查看自己的学习分析数据。
