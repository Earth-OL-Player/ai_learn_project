## 1. 项目启动步骤

### 1.1 必要的环境变量和中间件

本期继续复用 MySQL、用户和 JWT 能力，并新增默认题库相关表：`questions`、`knowledge_points`、`question_knowledge_points`。

必要中间件：

- MySQL 8.4 LTS，详见 `doc/中间件/MySQL.md`。

必要环境变量：

| 环境变量 | 示例占位符 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | `jdbc:mysql://127.0.0.1:3306/ai_learn?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false` | 本地 MySQL JDBC 地址 |
| `DATABASE_USERNAME` | `ai_learn_user` | 本地业务库账号 |
| `DATABASE_PASSWORD` | `本地业务用户密码占位符` | 本地业务库密码，禁止提交真实值 |
| `SPRING_FLYWAY_ENABLED` | `true` | 启用 Flyway 自动建表和初始化默认题库 |
| `JWT_SECRET` | `至少32位JWT密钥占位符` | JWT 签名密钥，禁止提交真实值 |
| `JWT_EXPIRES_IN_SECONDS` | `7200` | access token 过期秒数 |
| `VITE_API_BASE_URL` | `http://localhost:8080/api/v1` | 前端访问后端 API 的基础地址 |

数据库初始化验收：

1. 启动后端后确认 Flyway 已执行 `V4__init_question_tables.sql`。
2. 在 MySQL 中执行 `SHOW TABLES;`，应看到 `questions`、`knowledge_points`、`question_knowledge_points`。
3. 执行 `SELECT COUNT(1) FROM questions WHERE source_type = 'DEFAULT';`，应存在初始化示例题。
4. 执行 `SELECT COUNT(1) FROM knowledge_points;`，应存在 RAG、Embedding、Agent 等知识点。

## 2. 前端页面和功能验收

### 2.1 游客访问热门面经登录引导

验收步骤：

1. 清理浏览器登录态或退出登录。
2. 访问 `http://localhost:5173/interview-questions`。
3. 观察页面跳转和弹窗提示。

验收点：

- 游客不能直接进入热门面经页面。
- 页面跳转到学习路线页，并弹出登录引导。
- 登录引导提示用户登录后即可使用该功能。

### 2.2 登录用户查看题目列表

验收步骤：

1. 登录或注册账号。
2. 点击左侧菜单 `热门面经`。
3. 查看题目列表和分页区域。

验收点：

- 页面展示清新简约的热门面经头图、筛选区、列表区。
- 列表能展示初始化示例题。
- 每条题目展示标题、难度、题型、标签、知识点摘要和创建时间。
- 页面不展示数据库字段、内部来源字段或刷题提交入口。

### 2.3 题目筛选和分页

验收步骤：

1. 在关键词输入框输入 `RAG` 后点击查询。
2. 选择难度、题型或知识点筛选。
3. 点击重置按钮。
4. 如数据超过一页，切换分页。

验收点：

- 关键词可匹配题目标题或内容。
- 难度、题型、知识点筛选生效。
- 筛选条件变化后自动回到第一页。
- 无匹配题目时展示友好空状态。
- 重置后恢复全部默认题目列表。

### 2.4 题目详情查看

验收步骤：

1. 在热门面经列表点击任意题目卡片。
2. 查看题目详情弹窗。
3. 关闭弹窗后点击另一道题。

验收点：

- 详情弹窗展示题目标题、内容、难度、题型、标签和知识点。
- 详情弹窗展示参考答案和解析。
- 不展示 `source_type`、`deleted`、`owner_user_id` 等内部字段。
- 详情加载失败时展示中文错误提示。

### 2.5 后端接口联调验收

验收步骤：

1. 游客调用 `GET /api/v1/questions?pageNo=1&pageSize=10`。
2. 游客调用 `GET /api/v1/knowledge-points`。
3. 登录后携带 `Authorization: Bearer <accessToken占位符>` 调用题目列表、题目详情、知识点列表接口。
4. 登录后调用不存在的题目详情，例如 `GET /api/v1/questions/999999999`。

验收点：

- 游客调用题库相关接口返回 `AUTH_UNAUTHORIZED`。
- 登录用户调用 `GET /api/v1/questions` 返回统一分页响应，包含 `records`、`pageNo`、`pageSize`、`total`。
- 登录用户调用 `GET /api/v1/knowledge-points` 返回知识点列表。
- 登录用户调用 `GET /api/v1/questions/{id}` 返回题目内容、参考答案、解析和知识点。
- 不存在的题目返回 `RESOURCE_NOT_FOUND`。
- `pageSize` 大于 100 时，后端最多按 100 条处理。
