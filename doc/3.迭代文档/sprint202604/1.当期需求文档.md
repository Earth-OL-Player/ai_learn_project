# sprint202604 当期需求文档

版本：v1.0  
日期：2026-05-14  
迭代定位：面试题大全与默认题库基础  
前置依赖：sprint202601、sprint202602、sprint202603

## 1. 当期目标

把“面试题大全”从占位页升级为登录后可浏览的基础题库页面，同时沉淀默认题库数据结构，为 sprint202605 的刷题 Agent 提供题目来源。

完成后应达到：

- 登录用户可以访问面试题大全。
- 可以分页浏览默认题库。
- 可以按关键词、难度、题型、知识点进行基础筛选。
- 可以查看题目详情、参考答案和解析。
- 游客访问面试题大全时仍看到登录引导。

## 3. 题目字段需求

| 字段 | 说明 |
| --- | --- |
| title | 题目标题 |
| content | 题目内容 |
| questionType | 题型：SHORT_ANSWER、CHOICE、CODE、SCENARIO，本期优先 SHORT_ANSWER |
| difficulty | 难度：EASY、MEDIUM、HARD |
| tags | 标签，JSON 或逗号分隔均可，但接口返回数组 |
| knowledgePoints | 知识点列表 |
| standardAnswer | 参考答案 |
| analysis | 解析 |
| sourceType | DEFAULT、USER_UPLOAD、AI_GENERATED，本期只使用 DEFAULT |

## 4. 接口需求

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/questions` | 登录用户 | 题目分页列表，支持筛选 |
| GET | `/api/v1/questions/{id}` | 登录用户 | 题目详情 |
| GET | `/api/v1/knowledge-points` | 登录用户 | 知识点列表，用于筛选 |

列表查询参数：

| 参数 | 说明 |
| --- | --- |
| pageNo | 页码，从 1 开始 |
| pageSize | 每页数量，默认 10，最大 100 |
| keyword | 标题或内容关键词 |
| difficulty | 难度 |
| questionType | 题型 |
| knowledgePointId | 知识点 ID |

## 5. 页面需求

面试题大全页面包含：

- 筛选区：关键词、难度、题型、知识点。
- 列表区：标题、难度、题型、标签、知识点摘要。
- 详情区：题目内容、参考答案、解析、知识点。
- 空状态：无匹配题目时展示友好提示。

## 6. 验收标准

- 游客访问面试题大全会看到登录引导。
- 登录用户可以进入面试题大全页面。
- 页面能展示初始化示例题。
- 筛选和分页能正常工作。
- 题目详情不展示内部字段或数据库实现细节。
- 本期不出现刷题提交入口，避免与下一迭代边界混淆。
