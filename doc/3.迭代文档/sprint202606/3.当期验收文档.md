## 2. 前端页面和功能验收

### 2.1 我的题库

验收步骤：

1. 登录后点击右上角用户菜单“我的题库”。
2. 点击“新增题目”，填写标题、内容、题型、难度、标签、知识点和参考答案。
3. 保存后查看列表。

验收点：

- 新增题目展示在我的题库列表。
- 支持关键词、难度、题型筛选。
- 点击“查看答案”能看到参考答案和解析。
- 点击删除后题目从当前用户列表消失。

### 2.2 JSON 导入

验收步骤：

1. 点击“JSON 导入”。
2. 选择追加或全量替换。
3. 粘贴题目 JSON 数组并提交。

验收点：

- 追加导入不影响已有个人题目。
- 全量替换只替换当前用户个人题库。
- JSON 格式错误时前端给出提示。

### 2.3 刷题范围

验收步骤：

1. 进入 AI智能刷题。
2. 将题库范围切换为“我的题库”或“混合题库”。
3. 点击开始刷题。

验收点：

- “我的题库”只推荐当前用户个人题目。
- “混合题库”可从默认题库和个人题库中推荐。
- 推荐原因在题目下方展示。
