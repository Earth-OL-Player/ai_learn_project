## 1. 当期目标

在默认题库和基础刷题闭环之上，补齐个人题库最小可用能力。用户可以维护自己的题目来源，并在刷题时让个人题库参与推荐。

完成后应达到：

- 登录用户可以查看“我的题库”。
- 登录用户可以通过文本表单新增个人题目。
- 支持批量导入 JSON 格式题目，导入方式支持追加和全量替换。
- AI智能刷题开始时可以选择“默认题库 / 我的题库 / 混合题库”。
- 用户只能查看、导入、删除自己的个人题目。

## 3. 功能需求

### 3.1 我的题库

- 列表支持分页、关键词、难度、题型筛选。
- 列表只返回 `owner_user_id = 当前用户ID` 的题目。
- 默认题库不允许在我的题库页面编辑或删除。

### 3.2 题目导入

导入字段：

| 字段 | 说明 |
| --- | --- |
| title | 必填，题目标题 |
| content | 必填，题目内容 |
| questionType | 必填，SHORT_ANSWER、CHOICE、CODE、SCENARIO |
| difficulty | 必填，EASY、MEDIUM、HARD |
| tags | 可选，字符串数组 |
| knowledgePoints | 可选，字符串数组 |
| standardAnswer | 必填，参考答案 |
| analysis | 可选，解析 |

导入模式：

- `APPEND`：追加导入，不影响已有个人题目。
- `REPLACE`：先逻辑删除当前用户个人题目，再导入新题。

## 4. 接口需求

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/my-questions` | 登录用户 | 我的题库分页列表 |
| POST | `/api/v1/my-questions` | 登录用户 | 新增个人题目 |
| POST | `/api/v1/my-questions/import` | 登录用户 | 批量导入个人题库 |
| DELETE | `/api/v1/my-questions/{id}` | 登录用户 | 删除个人题目 |
| POST | `/api/v1/agent/practice/start` | 登录用户 | 增加 sourceScope 参数 |

## 5. 验收标准

- 用户可以新增个人题目并在我的题库列表中看到。
- JSON 导入格式错误时给出明确提示，不产生半导入脏数据。
- 全量替换只影响当前用户的个人题库，不影响默认题库和其他用户。
- 刷题选择“我的题库”时只推荐当前用户个人题。
- 游客访问我的题库接口返回登录引导。
