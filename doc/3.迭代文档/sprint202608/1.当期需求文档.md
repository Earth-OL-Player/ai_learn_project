# sprint202608 当期需求文档

版本：v1.0  
日期：2026-05-14  
迭代定位：RAG 入库与 Qdrant 检索  
前置依赖：sprint202601 - sprint202607

## 1. 当期目标

接入 Qdrant，完成学习资料和题库内容的最小 RAG 入库、检索能力，为后续智能推荐和生成题目提供知识片段。

## 2. 当期范围

| 编号 | 需求项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| S08-R01 | Qdrant 接入 | ai-service 连接 Qdrant，启动时校验集合 | P0 |
| S08-R02 | 入库任务 | 提交学习资料或题库入库任务并查询状态 | P0 |
| S08-R03 | 文档切分 | 对 Markdown 和题库字段进行基础切分 | P0 |
| S08-R04 | 向量检索 | 按问题文本检索相关知识片段 | P0 |
| S08-R05 | 后端管理接口 | 后端转发入库任务和检索请求，前端不直连 AI 服务 | P1 |

## 3. 接口需求

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/internal/v1/rag/index-tasks` | 内部 Token | 提交入库任务 |
| GET | `/internal/v1/rag/index-tasks/{taskId}` | 内部 Token | 查询任务状态 |
| POST | `/internal/v1/rag/search` | 内部 Token | 检索知识片段 |

## 4. 验收标准

- 本地 Qdrant 启动后，ai-service 可创建或复用集合。
- 提交入库任务后，任务状态可从 PENDING 变为 SUCCESS 或 FAILED。
- 检索 RAG、Embedding 等问题时可以返回相关学习片段或题库片段。
- 配置和文档均使用占位符，不提交真实密钥。
