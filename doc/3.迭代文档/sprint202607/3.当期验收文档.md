## 1. 项目启动步骤

### 1.1 必要的环境变量和中间件

本期不新增中间件，新增 AI 服务本地配置：

```powershell
$env:AI_SERVICE_TOKEN="AI_SERVICE_TOKEN本地占位符"
$env:AI_SERVICE_ENABLED="true"
$env:AI_SERVICE_BASE_URL="http://127.0.0.1:8000"
$env:AI_SERVICE_TIMEOUT_SECONDS="5"
```

### 1.2 启动 AI 服务

```powershell
cd ai-service
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

健康检查：`http://localhost:8000/health`。

### 1.3 启动后端和前端

后端和前端启动步骤沿用 sprint202606。

## 2. 功能验收

### 2.1 AI 服务评分接口

验收步骤：

1. 启动 AI 服务。
2. 携带 `X-Internal-Token` 调用 `/internal/v1/agent/answer/grade`。
3. 去掉或修改 Token 再调用一次。

验收点：

- Token 正确时返回结构化评分。
- Token 缺失或错误时返回 401。
- 返回字段包含 score、hitPoints、missingPoints、referenceAnswer、improvementAdvice。

### 2.2 后端评分适配

验收步骤：

1. 后端启用 `AI_SERVICE_ENABLED=true` 后提交答案。
2. 关闭 AI 服务后再次提交答案。

验收点：

- AI 服务可用时评分来源为 `AI_SERVICE`。
- AI 服务不可用时自动降级为 `LOCAL_RULE`。
- 降级不影响答题记录保存和成长反馈。
