## 2. 前端页面和功能验收

### 2.1 真实题库数据初始化

验收步骤：

1. 准备一个已执行到上一迭代的本地 MySQL 数据库，或准备全新本地 MySQL 数据库。
2. 启动 `ai-learn-backend`，确认 Flyway 执行到 `V12__remove_foreign_keys_and_knowledge_tables.sql`。
3. 在 MySQL 中执行题库数量和样例查询。

验收点：

- `questions` 表中未删除题目数量为 300。
- 题目编码包含 `AI-TOP-0001` 到 `AI-TOP-0300` 形式的数据。
- 题目内容、分类、参考答案、重要性评分、真实面试出现次数与 `AI面试题Top300.csv` 对应。
- 旧的少量验证题目不再出现在默认系统题库中。

参考 SQL：

```sql
SELECT COUNT(1) FROM questions WHERE deleted = 0;
SELECT code, question_type, importance_score, occurrence_count FROM questions WHERE deleted = 0 ORDER BY id ASC LIMIT 5;
```

### 2.2 去除知识点表和题目知识点关系表

验收步骤：

1. 在 MySQL 中执行表结构查询。
2. 访问热门面经页面，观察筛选区和题目列表。
3. 打开任意题目详情。

验收点：

- `knowledge_points` 表不存在。
- `question_knowledge_points` 表不存在。
- 热门面经页面不再展示“知识点”筛选项。
- 题目列表和详情弹窗不再展示知识点信息。
- 后端不再提供 `/api/v1/knowledge-points` 作为有效业务接口。

参考 SQL：

```sql
SHOW TABLES LIKE 'knowledge_points';
SHOW TABLES LIKE 'question_knowledge_points';
```

### 2.3 分类下拉框从题目表统计

验收步骤：

1. 登录普通用户，进入“热门面经”页面。
2. 展开“分类”下拉框。
3. 选择任意分类并点击查询。
4. 调用或观察 `GET /api/v1/questions/types` 返回结果。

验收点：

- 分类筛选是下拉框，不再需要手动输入分类。
- 下拉框选项来自 `questions.question_type` 的 distinct 结果。
- 选择某个分类后，题目列表只展示该分类题目。
- 清空分类后，可以恢复查看全部题目。

参考 SQL：

```sql
SELECT DISTINCT question_type FROM questions WHERE deleted = 0 ORDER BY question_type ASC;
```

### 2.4 去除系统所有外键设计

验收步骤：

1. Flyway 执行完成后，在当前业务库执行外键查询。
2. 尝试清理或删除本地测试数据，确认不再被数据库外键阻塞。

验收点：

- 当前业务库查询不到 `FOREIGN KEY` 约束。
- 历史表仍保留主键、唯一索引和必要查询索引。
- 数据清理不再因历史外键关系失败。

参考 SQL：

```sql
SELECT TABLE_NAME, CONSTRAINT_NAME
FROM information_schema.TABLE_CONSTRAINTS
WHERE CONSTRAINT_SCHEMA = DATABASE()
  AND CONSTRAINT_TYPE = 'FOREIGN KEY';
```

### 2.5 系统题库管理和 AI 智能刷题兼容

验收步骤：

1. 使用超级管理员登录，进入“管理者中心 > 系统题库管理”。
2. 查看题目列表和分类筛选。
3. 新增或编辑一条题目，将重要性评分设置为 88.8。
4. 使用普通用户进入“AI智能刷题”，选择分类后开始刷题。

验收点：

- 系统题库管理页面可正常分页查询真实题库。
- 重要性评分输入支持 1 位小数。
- 保存小数评分后，列表展示和后端返回均正常。
- AI 智能刷题仍能按分类抽取题目。
- 题目卡片可展示小数重要性评分，不影响评分和讨论流程。
