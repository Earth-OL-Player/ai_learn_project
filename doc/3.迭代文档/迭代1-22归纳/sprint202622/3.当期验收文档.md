## 2. 前端页面和功能验收

### 2.1 AI智能刷题评分链路

验收步骤：

1. 启动 MySQL、ai-service、ai-learn-backend 和 ai-learn-web；Qdrant 当前未接入主业务链路，除非专项验证 RAG 预留接口，否则无需部署。
2. 登录普通用户，进入 AI 智能刷题页面。
3. 选择任意题目分类并点击“开始”。
4. 输入当前题答案并发送。

验收点：

- 页面正常展示题目卡片。
- 提交答案后正常展示评分卡片，包含得分、命中点、缺失点、参考答案、优化建议和经验变化。
- AI 服务配置真实模型时，评分链路使用 `init_chat_model` 初始化模型，并通过 `create_agent(..., response_format=PracticeGradeResponse)` 返回结构化评分；模型异常或未配置时，仍返回本地兜底评分。
- 后端 `user_practice_sessions.last_grading_summary` 写入当前题评分摘要。

### 2.2 当前题多轮讨论记忆

验收步骤：

1. 在完成评分后，连续向 AI 追问三轮问题。
2. 第三轮问题使用“刚才说的第二点是什么意思”“前面那个方案有什么缺点”等指代表达。
3. 观察 AI 回复是否能结合前序讨论回答。

验收点：

- 后端 `user_practice_sessions.discussion_history_json` 持续追加当前题用户疑问和 AI 回复。
- 第三轮追问时，AI 服务请求上下文包含当前题、参考答案、最近一次答案、评分摘要、前两轮历史和当前疑问。
- 点击“下一题”或“重答本题”后，旧讨论历史被清空，不串题。

### 2.3 流式讨论链路

验收步骤：

1. 在评分完成后输入一个本题相关追问。
2. 观察页面 AI 回复展示过程。

验收点：

- 前端仍通过原 `/api/v1/practice/messages/stream` 接口接收 SSE。
- Python AI 服务优先使用 `create_agent(...).stream(..., stream_mode="messages")` 读取模型片段；若 Agent 包装层无可见 token，则切换到底层 `init_chat_model(...).stream(...)`，保证前端获得真正分片。
- Java 后端继续通过 `SseEmitter` 输出 `message` 和 `result` 事件。
- 模型流式异常时，页面可收到兜底提示，不出现无限等待。

### 2.4 无关问题本地拦截

验收步骤：

1. 在答题阶段输入“今天股票怎么样”。
2. 在讨论阶段输入“讲个笑话”。

验收点：

- 后端直接返回刷题上下文提示，不调用 Python AI 服务相关性接口。
- Python AI 服务已下线 `/internal/v1/practice/relevance` 路由。
- 明显无关词包含天气、新闻、股票、旅游、做饭、写诗、翻译、笑话、帅、好看、星座。
