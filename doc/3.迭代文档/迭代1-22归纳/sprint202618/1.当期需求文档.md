# sprint2618 当期需求文档

版本：v1.0  
日期：2026-05-17  
迭代定位：热门面经从查询列表式体验升级为类 Markdown 阅读体验，和路线资料页保持一致的左侧目录、右侧正文布局。

## 1. 背景与目标

当前热门面经页面以筛选、分页、列表卡片和详情弹窗为主，适合查询单题，但不适合连续阅读和按分类系统复习。功能设想要求将热门面经调整为类 Markdown 文档渲染方式，视觉风格保持与“路线和资料”功能一致，彻底去除原有查询列表式页面表达。

本迭代目标如下：

1. 热门面经页面改为左侧目录、右侧正文的沉浸式阅读布局。
2. 目录以题目分类生成，分类名称在正文中作为二级标题展示。
3. 题目内容不得作为标题展示，避免目录被题目刷屏。
4. 正文按类 Markdown 风格渲染题目、元信息和参考答案。
5. 页面风格保持清新、简约、大气，复用路线资料页的阅读卡片和目录样式。
6. 去除当前筛选查询、分页列表、详情弹窗等查询表格化体验。

## 2. 需求范围

### 2.1 页面布局

热门面经页面需要采用两栏阅读布局：

| 区域 | 要求 |
| --- | --- |
| 左侧目录 | 展示题目分类目录，支持点击跳转到对应分类正文。 |
| 右侧正文 | 按分类连续展示题目内容、题目元信息和参考答案。 |
| 目录状态 | 支持收起和展开，保持与路线资料页一致的交互体验。 |
| 当前定位 | 滚动正文时高亮当前分类目录项。 |

### 2.2 Markdown 展示规则

1. 页面正文顶部展示“热门面经”一级标题和简短说明。
2. 每个题目分类展示为二级标题，例如 `## RAG`。
3. 题目内容只作为正文块中的加粗文本展示，不作为 `h3/h4` 等标题。
4. 每道题展示题目编码、重要性、真实面试出现次数等辅助信息。
5. 参考答案支持按 Markdown 段落、列表、代码等常见格式渲染。
6. 当暂无题目时，需要展示清晰的空状态文案。

### 2.3 数据来源

1. 热门面经仍使用系统题库中的未删除题目。
2. 页面需要一次性获取可阅读的题目详情数据，避免用户逐题打开弹窗。
3. 题目分类以接口返回的分类文案为准。
4. 分类内题目优先按重要性和真实面试出现次数展示，方便用户优先阅读高频内容。

### 2.4 移除旧交互

本迭代移除热门面经页的以下查询式体验：

1. 关键词筛选表单。
2. 分类下拉筛选。
3. 分页列表卡片。
4. 题目详情弹窗。
5. 刷新按钮放在列表卡片头部的旧布局。

### 2.5 非功能需求

1. 本迭代禁止新增单元测试代码。
2. 不引入新的 MySQL、Redis、Qdrant 等中间件依赖。
3. 不提交真实密码、Token、密钥、生产连接地址等敏感信息。
4. Markdown 渲染不得开启接口数据中的原始 HTML 执行能力，降低内容注入风险。
5. 代码和文档统一使用 UTF-8 简体中文。
