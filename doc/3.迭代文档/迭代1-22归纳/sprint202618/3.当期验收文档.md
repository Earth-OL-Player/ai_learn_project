## 2. 前端页面和功能验收

### 2.1 热门面经阅读布局

验收步骤：

1. 启动后端和前端服务。
2. 使用普通用户登录系统。
3. 点击顶部导航“热门面经”，或直接访问 `/interview-questions`。

验收点：

- 页面展示左侧目录、右侧正文的阅读布局。
- 左侧目录展示题目分类，不展示单道题目标题。
- 右侧正文顶部展示“热门面经”标题和说明文案。
- 页面不再展示关键词筛选、分类筛选、分页列表和题目详情弹窗入口。

### 2.2 分类目录和正文跳转

验收步骤：

1. 在热门面经页面观察左侧目录。
2. 点击任意分类目录项。
3. 滚动右侧正文到其他分类区域。
4. 点击目录“收起”和“展开”按钮。

验收点：

- 目录项由正文中的二级分类标题生成。
- 点击目录后页面跳转到对应分类正文。
- 滚动正文时，左侧当前分类目录项会高亮。
- 目录收起后正文区域自动扩展，展开后恢复双栏布局。

### 2.3 题目和参考答案展示

验收步骤：

1. 在热门面经正文中查看任意分类下的题目。
2. 检查题目、题目元信息和参考答案展示样式。
3. 准备一条包含 Markdown 列表或代码片段的参考答案进行页面查看。

验收点：

- 分类名称以二级标题展示。
- 题目内容以“题目 N：xxx”的加粗正文展示，不作为标题进入目录。
- 每道题展示题目编码、重要性和真实面试出现次数。
- 参考答案按 Markdown 段落、列表、代码等格式展示。
- 接口数据中的原始 HTML 不会直接作为 HTML 执行。

### 2.4 空数据和异常场景

验收步骤：

1. 在本地数据库中临时清空或下架题库数据后刷新热门面经页面。
2. 恢复题库数据后再次刷新页面。
3. 临时停止后端服务后刷新页面。

验收点：

- 无题目数据时展示“暂无热门面经内容，管理员补充题库后将自动展示”。
- 恢复题库数据后页面可重新展示阅读正文。
- 接口请求失败时页面弹出“热门面经加载失败”或后端返回的错误信息。
