# sprint202603 当期需求文档

版本：v1.0  
日期：2026-05-14  
迭代定位：建议评论区最小闭环  
前置依赖：sprint202601、sprint202602

## 1. 当期目标

在已有登录权限基础上，实现建议评论区页面的真实数据闭环。游客可以查看，登录用户可以发布。

完成后应达到：

- 游客可分页查看建议列表和评论列表。
- 登录用户可提交建议和发表评论。
- 游客点击发布时看到“登录后即可使用该功能”。
- 建议状态默认为待处理，评论点赞和回复字段仅预留。

## 3. 建议需求

### 3.1 列表展示

| 字段 | 要求 |
| --- | --- |
| 标题 | 必须展示 |
| 内容摘要 | 必须展示 |
| 类型 | 展示中文文案 |
| 状态 | 展示中文文案，创建后为待处理 |
| 提交用户 | 昵称优先，无昵称展示用户名 |
| 提交时间 | 本地化展示 |

### 3.2 提交表单

| 字段 | 要求 |
| --- | --- |
| title | 必填，2 - 80 位 |
| type | 必填，FEATURE、EXPERIENCE、CONTENT、BUG、OTHER |
| content | 必填，5 - 2000 位 |

## 4. 评论需求

### 4.1 列表展示

| 字段 | 要求 |
| --- | --- |
| 内容 | 必须展示 |
| 用户头像 | 空值时展示默认头像 |
| 用户昵称 | 昵称优先，无昵称展示用户名 |
| 发布时间 | 本地化展示 |
| 点赞数 | 本期可展示 0，也可隐藏 |

### 4.2 发布表单

| 字段 | 要求 |
| --- | --- |
| content | 必填，2 - 1000 位 |
| parentId | 本期前端不传，后端字段预留 |

## 5. 接口需求

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/suggestions?pageNo=1&pageSize=10` | 游客 | 分页查询建议 |
| POST | `/api/v1/suggestions` | 登录用户 | 提交建议 |
| GET | `/api/v1/comments?pageNo=1&pageSize=10` | 游客 | 分页查询评论 |
| POST | `/api/v1/comments` | 登录用户 | 发表评论 |

所有列表使用统一分页响应。

## 6. 验收标准

- 游客能看到建议和评论列表。
- 游客发布建议或评论时弹出登录引导。
- 登录用户提交建议成功后，列表能看到新建议。
- 登录用户发表评论成功后，列表能看到新评论。
- 非法表单输入被前后端拦截。
- 响应中的作者信息不包含密码哈希、邮箱可按设计隐藏或展示。
