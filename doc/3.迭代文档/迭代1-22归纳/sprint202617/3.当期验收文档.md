## 3. 后端规则验收

### 3.1 等级经验展示

验收步骤：

1. 准备一个已有答题数据的测试用户。
2. 确认该用户所有题目历史最高分总和为 700。
3. 使用该用户登录系统。
4. 调用 `GET /api/v1/growth/me` 或查看个人中心。

验收点：

- `currentExperience` 返回 `700`。
- `level` 返回 `LV8`。
- `levelProgressText` 返回 `LV8 700/800`。
- 页面不再展示旧等级名称，如“AI 初识者”“AI 筑基者”等。

### 3.2 经验来源不变

验收步骤：

1. 进入 AI 智能刷题页面。
2. 首次回答一道题并记录得分。
3. 重答同题但分数低于历史最高分。
4. 再次查看个人中心和成长概览。
5. 重答同题并让分数高于历史最高分。

验收点：

- 首次回答后，总经验增加该题得分。
- 未突破历史最高分时，总经验不增加。
- 突破历史最高分时，总经验只增加突破差值。
- `/growth/me` 的总经验与 `user_question_stats.best_score` 汇总结果一致。

## 4. 前端页面验收

### 4.1 个人中心

验收步骤：

1. 登录系统。
2. 进入“个人中心”。
3. 查看顶部用户信息区域和资料表。
4. 查看成长概览区域。

验收点：

- 顶部基础资料卡只展示头像、昵称、用户名和基础资料，成长角色不重复展示。
- 资料表展示“当前总经验”“等级经验”“修仙境界”。
- “等级经验”格式类似 `LV8 700/800`。
- 成长概览中展示当前角色形象、总经验、累计答题、平均得分和连续学习。
- 进度条按当前等级内经验计算，例如 LV8 的进度基于 `700~800` 区间。
- 页面整体留白舒适，风格清新简约。

### 4.2 AI 智能刷题左侧栏

验收步骤：

1. 登录系统。
2. 进入“AI 智能刷题”页面。
3. 查看左侧栏顶部修炼文案和角色卡。
4. 完成一次答题评分后观察左侧栏是否刷新。

验收点：

- 左侧不再重复展示独立经验卡。
- 顶部文案展示为两行修炼语：昨日因，今日果，前尘不咎；今日因，明日果，当下即道。
- 文案下方展示当前用户昵称、`LVx 当前总经验/下级总经验` 和对应境界 Q 版角色形象。
- 答题后若经验变化，左侧栏等级、经验和角色境界同步刷新。
- 移动端宽度下，左侧栏和聊天区可以自然上下堆叠。

## 5. MySQL 验收

验收步骤：

1. 启动后端并确认 Flyway 执行成功。
2. 在 MySQL 执行以下 SQL。

```sql
DESC users;
SELECT version, description, success FROM flyway_schema_history WHERE version = '14';
SELECT id, username, experience, level_code, rank_code FROM users WHERE username = '本地用户名占位符';
SELECT COALESCE(SUM(best_score), 0) AS total_experience FROM user_question_stats WHERE user_id = 用户ID占位符;
```

验收点：

- `flyway_schema_history` 中 V14 执行成功。
- `users.rank_code` 字段长度为 `VARCHAR(32)`。
- `users.rank_code` 默认值为 `QI_REFINING`。
- 历史通用段位编码不再作为新注册用户默认值。
- 用户登录、查看个人信息或完成答题后，`level_code` 和 `rank_code` 会按最新规则刷新。
