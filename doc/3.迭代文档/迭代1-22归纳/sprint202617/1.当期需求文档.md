# sprint2617 当期需求文档

版本：v1.0  
日期：2026-05-17  
迭代定位：经验等级与修仙境界段位重构，优化个人中心和 AI 智能刷题左侧成长展示，并接入统一风格段位角色形象。

## 1. 背景与目标

当前成长体系仍保留旧等级名称和青铜、白银等通用段位，对 AI 学习产品的主题感和进阶反馈不足。用户在个人中心和 AI 智能刷题页面只能看到分散的等级、经验、段位信息，不容易理解“距离升级还差多少”和“当前段位形象”。

本迭代目标如下：

1. 等级去除名称，从 `LV1` 开始按总经验展示。
2. 每 100 总经验升 1 级，展示格式为 `LV8 700/800`。
3. 总经验继续按所有题目历史最高分累计，不改变答题经验沉淀算法。
4. 段位改为中国风修仙境界，由等级范围映射得到。
5. 个人中心和 AI 智能刷题左侧栏统一展示等级经验、修仙境界和用户昵称。
6. 生成并接入同一套 Q 版修仙角色形象，整体 UI 保持清新、简约、大气。

## 2. 需求范围

### 2.1 等级和经验规则

等级规则：

| 规则项 | 要求 |
| --- | --- |
| 起始等级 | `LV1` |
| 升级步长 | 每 100 总经验升 1 级 |
| 等级名称 | 不再展示等级名称 |
| 当前总经验 | 展示历史最高分累计得到的当前总经验 |
| 升级要求总经验 | 展示升级到下一等级所需总经验 |

示例：

```text
LV8 700/800
```

含义：当前处于 `LV8`，当前总经验为 `700`，达到 `800` 总经验后升级到 `LV9`。

### 2.2 经验来源规则

总经验算法保持不变：

1. 用户每道题只取历史最高分。
2. 当前总经验等于所有已答题目历史最高分之和。
3. 重答未突破历史最高分时，总经验不增加。
4. 重答突破历史最高分时，总经验只增加突破差值。

### 2.3 修仙境界段位映射

段位由等级映射得到：

| LV 范围 | 境界 |
| --- | --- |
| LV1 ~ LV10 | 炼气期 |
| LV11 ~ LV20 | 筑基期 |
| LV21 ~ LV30 | 金丹期 |
| LV31 ~ LV40 | 元婴期 |
| LV41 ~ LV50 | 化神期 |
| LV51 ~ LV60 | 炼虚期 |
| LV61 ~ LV70 | 合体期 |
| LV71 ~ LV80 | 大乘期 |
| LV81 ~ LV90 | 渡劫期 |
| LV91 ~ LV100 | 真仙境 |
| LV101 ~ LV110 | 金仙境 |
| LV111 ~ LV120 | 太乙境 |
| LV121 ~ LV130 | 大罗境 |
| LV131 及以上 | 道祖境 |

说明：功能设想中道祖境范围为 `LV131 ~ LV140`，实现侧为避免超出 `LV140` 后无段位显示，将 `LV131` 及以上统一归入道祖境。

### 2.4 个人中心展示优化

个人中心需要展示：

1. 用户昵称、用户名和基础信息。
2. 当前总经验。
3. 等级经验文案，例如 `LV8 700/800`。
4. 修仙境界，例如 `炼气期`。
5. 当前境界对应 Q 版修仙角色形象。
6. 成长概览中的进度条按当前等级区间计算，而不是按总经验除以下一级总经验计算。

### 2.5 AI 智能刷题左侧栏展示优化

AI 智能刷题左侧栏需要展示：

1. 当前总经验。
2. 等级经验文案和修仙境界。
3. 当前用户昵称。
4. 当前修仙境界对应 Q 版角色形象。
5. 角色卡片放在左侧引导语下方，作为刷题陪伴形象，避免重复展示经验卡片。

### 2.6 段位角色形象

需要为 14 个修仙境界准备统一风格角色形象，风格要求：

- 中国风修仙题材。
- 可爱卡通人物，Q 版比例。
- 圆润可爱的脸型，明亮大眼睛。
- 古风服饰、仙侠元素、柔和光效。
- 服装和光效随境界逐渐升级。
- 干净背景、人物居中、全身正面站姿。
- 适合游戏角色进阶展示。

本迭代采用静态全身角色图展示，去除上下浮动效果，并通过透明人物图与浅色 UI 背景自然融合。

## 3. 非功能需求

1. 本迭代禁止新增单元测试代码。
2. 不提交真实密码、Token、密钥或生产连接地址。
3. 涉及 MySQL 表字段默认值或长度变化时，通过 Flyway migration 管理，并同步更新 `doc/中间件/MySQL.md`。
4. 前端 UI 保持清新、简约、大气，避免复杂装饰遮挡刷题主流程。
5. 生成和引用的静态图片资源必须放入前端工程公开资源目录，不能只引用本地临时文件。
6. 代码和文档统一使用 UTF-8 简体中文。
