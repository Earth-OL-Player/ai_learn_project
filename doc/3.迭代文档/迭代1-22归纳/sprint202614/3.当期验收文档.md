## 2. 前端页面和功能验收

### 2.1 AI 服务评分链路

验收步骤：

1. 确认后端配置 `AI_SERVICE_ENABLED=true`，且 `AI_SERVICE_BASE_URL` 指向本地 Python AI 服务。
2. 登录系统并进入 AI 智能刷题页面。
3. 点击“开始”抽取题目，输入一段答案并发送。

验收点：

- 页面能正常返回评分结果、命中点、缺失点、参考答案和经验变化。
- Python AI 服务日志不再出现请求体缺失导致的 422 `Field required`。
- Java 后端即使 AI 服务异常，也能自动使用本地规则兜底，不影响页面评分。

### 2.2 答题后不重复展示题目

验收步骤：

1. 抽取任意一道题目。
2. 提交答案并等待评分结果。

验收点：

- 出题时展示题目卡片。
- 评分消息中不再重复展示同一道题目的题干。
- 页面仍可继续点击“重答本题”或“下一题”。

### 2.3 兜底评分算法

验收步骤：

1. 抽取 `RAG 检索增强生成` 分类题目。
2. 使用同义表达回答核心流程，例如包含“文档解析、切分、向量化、检索召回、重排、提示词、基于证据生成答案”等内容，但不刻意复述完整分类名。
3. 查看评分详情中的缺失点。

验收点：

- 缺失点中不出现“缺少「RAG 检索增强生成」相关说明”。
- `向量化` 可命中 `Embedding`，`切分/分块` 可命中 `Chunk`，`重排/精排` 可命中 `Rerank`。
- 评分重点体现参考答案核心含义覆盖情况，而不是分类名复述情况。

### 2.4 讨论回复与评分详情样式

验收步骤：

1. 完成一次评分后，在输入框中继续追问本题。
2. 展开评分卡片中的“查看评分详情”。

验收点：

- 讨论回复直接给出解释或建议，不再出现“你的问题是……”这类复述用户问题的内容。
- 评分详情展开后左侧不贴边，命中点、缺失点、参考答案和经验变化都有清晰内边距。
- 页面整体保持清新简约风格。
