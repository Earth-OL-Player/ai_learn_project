## 1. 验收目标

本期验收目标是确认项目已经具备最小可运行底座：前端可以本地启动，后端可以本地启动，浏览器默认进入“路线和资料”页面，四个规划菜单可以正常展示和切换；学习路线页面直接渲染前端项目内 Markdown 原文，不调用后端接口获取内容。

本期不验收注册登录、数据库、建议评论、题库和AI智能刷题真实业务能力。

## 2. 环境要求

### 2.1 后端环境

- JDK：17 或以上版本。
- Maven：3.9 或以上版本。
- 默认端口：`8080`。

### 2.2 前端环境

- Node.js：20 或以上版本。
- npm：10 或以上版本。
- 默认端口：`5173`。

## 3. 需要修改或确认的配置

### 3.1 前端接口地址配置

配置文件示例：`ai-learn-web/.env.example`

```text
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

本地启动前建议复制一份 `.env`：

```powershell
cd ai-learn-web
Copy-Item .env.example .env
```

如果后端端口或部署地址发生变化，需要修改 `.env` 中的 `VITE_API_BASE_URL`。

注意：

- 示例值只能使用本地占位地址。
- 不得提交真实生产地址、密码、Token、密钥等敏感信息。

### 3.2 后端端口配置

配置文件：`ai-learn-backend/src/main/resources/application.yml`

```yaml
server:
  port: 8080
spring:
  application:
    name: ai-learn-backend
```

如果本地 `8080` 端口被占用，可以临时修改 `server.port`，同时需要同步修改前端 `.env` 中的 `VITE_API_BASE_URL`。

### 3.3 中间件配置

本期不依赖 MySQL、Redis、Qdrant 等中间件，不需要配置数据库、缓存或向量库连接信息。

如果后续迭代引入中间件，必须同步更新 `doc/中间件/` 下的对应说明文档。

### 3.4 学习路线 Markdown 配置

前端学习路线 Markdown 文件：

```text
ai-learn-web/src/content/learning-roadmap/AI应用开发学习路线和资料集.md
```

前端学习路线图片资源目录：

```text
ai-learn-web/src/content/learning-roadmap/AI应用开发学习路线和资料集.assets/
```

验收和维护要求：

- 页面必须直接渲染上述 Markdown 文件。
- 不得为展示效果改写 Markdown 文件内容。
- 后续修改页面内容时，直接修改前端项目中的 Markdown 文件。
- 如果 Markdown 新增图片，应将图片放入同级 `.assets` 目录，并使用相对路径引用。
- 学习路线页面不得调用后端接口获取内容。

## 4. 项目启动方式

### 4.1 启动后端

进入后端工程目录：

```powershell
cd ai-learn-backend
```

启动命令：

```powershell
mvn spring-boot:run
```

启动成功后，后端默认访问地址为：

```text
http://localhost:8080
```

### 4.2 启动前端

进入前端工程目录：

```powershell
cd ai-learn-web
```

安装依赖：

```powershell
npm install
```

启动命令：

```powershell
npm run dev
```

启动成功后，前端默认访问地址为：

```text
http://localhost:5173
```

## 5. 接口验收

### 5.1 健康检查接口

请求命令：

```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/health" -Method Get
```

验收点：

- 响应 `code` 为 `SUCCESS`。
- 响应 `data.status` 为 `UP`。
- 响应包含非空 `traceId`。
- 该接口不需要登录即可访问。

### 5.2 学习路线页面数据来源

学习路线页面不再验收后端学习路线接口调用。

验收点：

- 浏览器打开学习路线页面时，不依赖 `GET /api/v1/learning/roadmap` 获取内容。
- 页面内容来自 `ai-learn-web/src/content/learning-roadmap/AI应用开发学习路线和资料集.md`。
- Markdown 同级 `.assets` 目录中的图片可以正常展示。
- 页面左侧展示“目录”，点击目录项可以跳转到对应章节，当前阅读章节有高亮标识。
- 页面不得展示“本地 Markdown 静态页面”“直接修改前端 Markdown 文件即可同步页面内容”等内部维护提示。
- 修改前端项目内 Markdown 文件后，重新构建或开发环境热更新后页面内容同步变化。
