## 1. 验收目标

本期验收目标是确认项目已经具备最小可运行底座：前端可以本地启动，后端可以本地启动，浏览器默认进入“AI 学习路线与资料”页面，四个规划菜单可以正常展示和切换。

本期不验收注册登录、数据库、建议评论、题库和刷题 Agent 真实业务能力。

## 2. 环境要求

### 2.1 后端环境

- JDK：17 或以上版本。
- Maven：3.9 或以上版本。
- 默认端口：`8080`。

### 2.2 前端环境

- Node.js：20 或以上版本。
- npm：10 或以上版本。
- 默认端口：`5173`。

## 3. 需要修改或确认的配置

### 3.1 前端接口地址配置

配置文件示例：`ai-learn-web/.env.example`

```text
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

本地启动前建议复制一份 `.env`：

```powershell
cd ai-learn-web
Copy-Item .env.example .env
```

如果后端端口或部署地址发生变化，需要修改 `.env` 中的 `VITE_API_BASE_URL`。

注意：

- 示例值只能使用本地占位地址。
- 不得提交真实生产地址、密码、Token、密钥等敏感信息。

### 3.2 后端端口配置

配置文件：`ai-learn-backend/src/main/resources/application.yml`

```yaml
server:
  port: 8080
spring:
  application:
    name: ai-learn-backend
```

如果本地 `8080` 端口被占用，可以临时修改 `server.port`，同时需要同步修改前端 `.env` 中的 `VITE_API_BASE_URL`。

### 3.3 中间件配置

本期不依赖 MySQL、Redis、Qdrant 等中间件，不需要配置数据库、缓存或向量库连接信息。

如果后续迭代引入中间件，必须同步更新 `doc/中间件/` 下的对应说明文档。

## 4. 项目启动方式

### 4.1 启动后端

进入后端工程目录：

```powershell
cd ai-learn-backend
```

启动命令：

```powershell
mvn spring-boot:run
```

启动成功后，后端默认访问地址为：

```text
http://localhost:8080
```

### 4.2 启动前端

进入前端工程目录：

```powershell
cd ai-learn-web
```

安装依赖：

```powershell
npm install
```

启动命令：

```powershell
npm run dev
```

启动成功后，前端默认访问地址为：

```text
http://localhost:5173
```

## 5. 接口验收

### 5.1 健康检查接口

请求命令：

```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/health" -Method Get
```

验收点：

- 响应 `code` 为 `SUCCESS`。
- 响应 `data.status` 为 `UP`。
- 响应包含非空 `traceId`。
- 该接口不需要登录即可访问。

### 5.2 学习路线接口

请求命令：

```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/learning/roadmap" -Method Get
```

验收点：

- 响应 `code` 为 `SUCCESS`。
- 响应包含 `message`、`data`、`traceId`。
- `data.title` 为 `AI 应用开发学习路线和资料集`。
- `data.sections` 非空。
- `data.sections` 至少包含基础阶段、进阶阶段、工程阶段、实战阶段。
- 学习路线数据不依赖运行时读取 `doc/` 目录。

## 6. 前端功能验收

### 6.1 默认首页

验收步骤：

1. 浏览器访问 `http://localhost:5173/`。
2. 观察页面是否自动进入学习路线页面。

验收点：

- 根路径 `/` 自动跳转或展示 `/learning-roadmap` 内容。
- 页面标题为“AI 学习路线与资料”。
- 左侧“AI 学习路线与资料”菜单高亮。

### 6.2 全局布局

验收点：

- 页面左侧展示四个菜单：
  - AI 学习路线与资料
  - 建议与评论
  - 面试题大全
  - 刷题 Agent
- 页面顶部展示当前页面标题。
- 页面右上角展示“登录 / 注册”入口。
- 页面整体风格清新、简约、大气。

### 6.3 登录注册占位

### 6.4 学习路线页面

验收步骤：

1. 打开 `http://localhost:5173/learning-roadmap`。
2. 查看页面内容是否完整展示。
