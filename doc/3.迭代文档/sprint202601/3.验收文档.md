## 1. 项目启动步骤

### 1.1 必要的环境变量和中间件

本期不依赖 MySQL、Redis、Qdrant 等中间件。

前端接口地址示例：

```text
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

说明：示例配置仅使用本地占位地址，禁止提交真实生产地址、密码、Token、密钥等敏感信息。

### 1.2 启动后端

```powershell
cd ai-learn-backend
mvn spring-boot:run
```

启动成功后访问地址：

```text
http://localhost:8080
```

健康检查：

```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/health" -Method Get
```

预期结果：`code=SUCCESS`，`data.status=UP`，响应包含 `traceId`。

### 1.3 启动前端

```powershell
cd ai-learn-web
npm install
npm run dev
```

启动成功后访问地址：

```text
http://localhost:5173
```

说明：本项目当前要求禁止新增单元测试代码，验收文档只记录构建、接口联调和人工验收步骤。

## 2. 前端页面和功能验收

### 2.1 默认首页和全局布局

验收步骤：

1. 浏览器访问 `http://localhost:5173/`。
2. 点击左侧“路线和资料”“建议评论区”“热门面经”“AI智能刷题”。

验收点：

- 根路径 `/` 自动展示 `/learning-roadmap` 内容。
- 四个菜单展示完整，点击后路由切换正常，当前菜单高亮正确。
- 顶部不展示“当前页面 XXXXX”标题区。
- 页面整体风格清新、简约、大气。

### 2.2 登录注册占位

验收步骤：

1. 点击右上角“登录 / 注册”。

验收点：

- 页面出现中文提示。
- 提示说明登录能力将在 `sprint202602` 开放。
- 不跳转真实登录页，不调用真实登录接口。

### 2.3 学习路线页面

验收步骤：

1. 打开 `http://localhost:5173/learning-roadmap`。
2. 查看 Markdown 内容、目录和图片展示。

验收点：

- 页面直接渲染前端项目内 Markdown 文件。
- 标题、正文、表格、引用、列表、链接、图片均正常展示。
- 左侧目录支持点击跳转、当前阅读章节高亮、收起和展开。
- 图片下方展示图注，例如“图1-AI应用开发学习路线”。
- 页面不展示内部维护提示，不调用后端学习路线接口。

### 2.4 占位页面

验收步骤：

1. 点击“建议评论区”。
2. 点击“热门面经”。
3. 点击“AI智能刷题”。

验收点：

- 三个页面均展示明确标题和后续迭代开放说明。
- 路由与菜单高亮正确。
- 不出现接口报错或空白页。
