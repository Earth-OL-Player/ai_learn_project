## 1. 技术方案

本期采用前后端分离，但只实现最小可运行骨架。

```mermaid
flowchart LR
    browser["浏览器"] --> web["ai-learn-web"]
    web --> backend["ai-learn-backend"]
```

- 前端负责布局、路由和学习路线展示。
- 后端提供统一响应、traceId、健康检查和学习路线接口。
- 本期不连接数据库和其他中间件。

## 2. 前端设计

### 2.1 目录结构

```text
ai-learn-web/src/
├── api/
│   ├── http.ts
│   └── learning.ts
├── components/common/
├── layout/AppLayout.vue
├── pages/
│   ├── learning-roadmap/LearningRoadmapPage.vue
│   └── placeholder/PlaceholderPage.vue
├── router/index.ts
├── styles/global.scss
├── types/learning.ts
└── utils/
```

### 2.2 路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 重定向 | 重定向到 `/learning-roadmap` |
| `/learning-roadmap` | 学习路线 | 公开首页 |
| `/suggestions-comments` | 占位页 | sprint202603 实现 |
| `/interview-questions` | 占位页 | sprint202604 实现 |
| `/practice-agent` | 占位页 | sprint202605 实现 |

### 2.3 HTTP 封装

- `VITE_API_BASE_URL=http://localhost:8080/api/v1`。
- 响应 `code = SUCCESS` 时取 `data`。
- 非成功响应展示中文 `message`。
- 网络异常展示“网络异常，请稍后重试”。

## 3. 后端设计

### 3.1 包结构

```text
com.earth.online.player.ailearn
├── common/
│   ├── exception/
│   ├── response/
│   └── trace/
└── learning/
    ├── interfaces/
    └── application/
```

### 3.2 统一响应

```json
{
  "code": "SUCCESS",
  "message": "操作成功",
  "data": {},
  "traceId": "trace-id占位符"
}
```

### 3.3 学习路线接口

- Controller：`LearningRoadmapController`。
- 应用服务：`LearningRoadmapQueryService`。
- 数据来源：代码内静态 DTO 或 `resources/learning/roadmap.json`。
- 不运行时读取 `doc/`，避免部署后路径不可用。

## 4. 配置

### 4.1 前端 `.env.example`

```text
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

### 4.2 后端配置

只保留服务端口、应用名和日志级别，不配置数据库。

```yaml
server:
  port: 8080
spring:
  application:
    name: ai-learn-backend
```

## 5. 验证要求

本项目当前要求禁止新增单元测试代码，本期只整理接口联调、启动验证和人工验收清单。

- 接口验证：学习路线接口返回 `SUCCESS`，且 sections 非空。
- 前端验证：菜单切换正常，学习路线展示正常，占位页不报错。
- 构建验证：前端 `build` 成功，后端可启动并接口验证通过。

## 6. 开发顺序

1. 创建前端和后端工程。
2. 后端实现统一响应、traceId 和学习路线接口。
3. 前端实现布局、路由和 HTTP 封装。
4. 前端实现学习路线页面和占位页。
5. 补充启动说明和基础验证清单。
