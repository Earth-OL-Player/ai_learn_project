## 1. 当期目标

本迭代只完成“能打开、能导航、能看学习路线”的最小底座，不引入注册登录、数据库、建议评论、题库和刷题逻辑。

交付后应达到：

- 前端工程和后端工程可以本地启动。
- 浏览器默认进入“路线和资料”页面。
- 顶部横向展示四个规划菜单，主内容区能切换公开页面或显示后续迭代占位提示。
- 右上角展示登录入口占位，但不实现真实登录。
- 学习路线内容来自前端项目内复制的 `AI应用开发学习路线和资料集.md` 原文，页面以清新简约风格静态渲染，不调用后端接口获取内容。

### 2.2 本期不做

- 不做注册、登录、退出、JWT 和权限守卫。
- 不连接 MySQL、Redis、Qdrant。
- 不做建议、评论、面试题、AI智能刷题的真实接口。
- 不做个人中心、答题记录、成长体系。

## 3. 页面需求

### 3.1 全局布局

- 顶部横向主导航：路线和资料、AI智能刷题、热门面经、建议评论区。
- 默认高亮“路线和资料”。
- 顶部用户区展示“登录 / 注册”入口占位，点击提示“登录能力将在 sprint202602 开放”。
- 主内容区根据路由展示页面内容，顶部不展示“当前页面 XXXXX”标题区。

### 3.2 学习路线页面

页面要求：

- 前端项目内放置 `AI应用开发学习路线和资料集.md` 及其 `.assets` 图片目录。
- 页面直接渲染该 Markdown 原文，不得为展示效果改写 Markdown 文件内容。
- Markdown 中的标题、表格、引用、图片、链接、列表和正文应正常展示。
- 页面内容区左侧展示“目录”，目录根据 Markdown 二级到四级标题自动生成，当前阅读章节需要高亮标识。
- 面向用户的页面不得展示 Markdown 维护方式、文件路径或“直接修改前端 Markdown 文件即可同步页面内容”等内部提示。
- 后续直接修改前端项目中的 Markdown 文件后，页面内容应同步更新。
- 页面不调用后端学习路线接口获取内容。

### 3.3 占位页面

AI智能刷题、热门面经、建议评论区当前均为占位页，要求：

- 有明确标题。
- 有后续迭代说明。
- 不出现接口报错或空白页。

## 4. 接口需求

接口统一前缀：`/api/v1`。

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/health` 或 `/actuator/health` | 游客 | 后端健康检查 |

学习路线页面内容由前端 Markdown 静态渲染，本期不要求通过后端接口提供。

## 5. 非功能要求

- 文档、源码、配置统一 UTF-8。
- 前端 API 基础地址通过 `ai-learn-web/.env` 提供本地占位值，启动时由 Vite 读取。
- 后端响应遵循统一结构，包含 `code`、`message`、`data`、`traceId`。
- 不提交真实密码、Token、生产地址。
- 代码保持简单，避免为了后续功能过度抽象。

## 6. 验收标准

- `ai-learn-web` 可本地启动并访问。
- `ai-learn-backend` 可本地启动，健康检查可访问。
- 打开前端默认进入学习路线页面。
- 四个顶部菜单展示完整，顺序正确，当前菜单高亮正确。
- 学习路线页面渲染前端 Markdown 原文内容，图片、链接和页面内文档目录展示正常。
- 其他菜单点击后显示占位说明，不报错。
- 仓库未新增 MySQL、Redis、Qdrant 运行时依赖。
