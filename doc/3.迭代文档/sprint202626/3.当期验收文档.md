## 2. 前端页面和功能验收

### 2.1 全局桌面端布局

验收步骤：

1. 使用 1440px 或更宽桌面浏览器访问 `http://localhost:5173/home`。
2. 依次进入首页、路线和资料、AI智能刷题、热门面试题、建议评论区。
3. 登录后从用户菜单进入个人中心和管理者中心。

验收点：

- 顶部品牌区、横向主导航、登录/用户入口按桌面布局展示。
- 页面不出现底部手机导航。
- 主要页面没有页面级横向滚动。
- 原有电脑端阅读、刷题、互动、资料编辑和管理入口仍可使用。

### 2.2 手机端全局导航

验收步骤：

1. 使用 375px 手机视口访问 `http://localhost:5173/home`。
2. 查看顶部栏和底部固定导航。
3. 依次点击底部“首页、路线、刷题、面试、互动”入口。

验收点：

- 手机端顶部栏只保留品牌和登录/用户入口，不展示桌面横向菜单。
- 底部固定导航展示五个主要入口，并能正确切换页面。
- 页面主体底部有安全间距，最后一屏内容不会被底部导航遮挡。
- 375px 和 768px 宽度下没有页面级横向滚动。

### 2.3 首页与路线资料页

验收步骤：

1. 手机端进入首页。
2. 查看目录卡片、正文标题、正文段落和表格。
3. 手机端进入路线和资料页，查看目录、图片、表格和代码块。

验收点：

- Markdown 页面由桌面双栏切换为手机单列。
- 目录位于正文上方，可展开、收起和独立滚动。
- 正文卡片宽度贴合屏幕，标题和段落不被挤压。
- 宽表格和代码块只在自身容器内滚动，不撑出页面。

### 2.4 AI智能刷题页

验收步骤：

1. 手机端进入 AI智能刷题页。
2. 查看成长信息、分类选择、开始下一题、重答本题和输入栏。
3. 登录后选择分类并点击开始下一题，再输入答案点击发送。

验收点：

- 成长信息和对话区在手机端单列展示。
- 分类选择、开始下一题、重答本题、发送按钮均铺满或保持足够触控面积。
- 消息气泡、题目卡片、评分详情和输入栏不横向溢出。
- 底部导航不遮挡输入栏和对话区最后一屏内容。

### 2.5 热门面试题页

验收步骤：

1. 手机端进入热门面试题。
2. 展开分类区域并切换题目分类。
3. 查看题目卡片、重要性、真实面试次数和参考答案。

验收点：

- 分类导航在手机端位于正文上方。
- 题目标题和元信息自动换行，不出现横向溢出。
- 参考答案 Markdown 正常展示，页面纵向滚动流畅。

### 2.6 建议评论区

验收步骤：

1. 手机端进入建议评论区。
2. 切换建议区和评论区，切换最热和最新排序。
3. 登录后发布建议、发表评论、回复评论并点击点赞。

验收点：

- 页签、排序、发布框和发布按钮在手机端布局清晰。
- 建议类型按钮、文本输入框和回复框不撑出屏幕。
- 评论子列表、点赞、回复和分页可触控操作。

### 2.7 个人中心

验收步骤：

1. 手机端登录后进入个人中心。
2. 查看基础资料卡和成长概览。
3. 点击编辑资料，修改昵称或性别并保存。

验收点：

- 基础资料在手机端单列展示。
- 编辑资料弹窗宽度适配手机屏幕，底部按钮易于点击。
- 成长角色卡、指标卡、等级进度和徽章墙按单列展示。
- 保存后资料展示和全局登录态保持同步。

### 2.8 管理者中心

验收步骤：

1. 手机端使用超级管理员账号进入管理者中心。
2. 查看用户管理和系统题库管理。
3. 使用筛选表单、分页、新增/编辑弹窗和系统题库导入预检弹窗。

验收点：

- 管理侧栏在手机端变为顶部管理导航。
- 筛选表单、容量限制卡和题库操作按钮单列或自动换行。
- 表格只在卡片内部横向滚动，页面本身不横向滚动。
- 新增、编辑、导入预检弹窗不超过手机屏幕宽度。
