# sprint202626 当期需求文档

版本：v1.0  
日期：2026-05-23  
迭代定位：现有 Web 前端完整支持手机端浏览器访问

## 1. 背景

当前平台前端主要按电脑端浏览器设计，顶部导航、双栏内容、管理表格、刷题对话区和个人中心资料展示都优先使用桌面宽度。用户在手机端访问时容易出现横向拥挤、触控目标偏小、目录和表格难以操作等问题。

本迭代目标是在不削弱电脑端现有体验的前提下，为手机端提供符合移动浏览器习惯的布局和交互，让首页、路线资料、AI 智能刷题、热门面试题、建议评论区、个人中心和管理者中心均可在手机端完成核心操作。

## 3. 非功能要求

1. 本迭代只修改前端响应式布局和迭代文档，不新增 MySQL、Redis、Qdrant 等中间件依赖。
2. 不提交真实密码、Token、密钥、生产连接地址等敏感信息。
3. 代码注释、文档统一使用 UTF-8 简体中文。
4. 禁止编写单元测试代码，验收阶段使用构建命令和人工页面检查。
5. 移动端不得出现页面级横向滚动；确需展示宽表格时，只允许表格容器内部滚动。
