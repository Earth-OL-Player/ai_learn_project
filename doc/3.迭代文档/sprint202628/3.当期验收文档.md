## 2. 前端页面和功能验收

### 2.1 管理者中心日志管理入口

验收步骤：

1. 使用超级管理员账号登录系统。
2. 点击右上角用户菜单进入“管理者中心”。
3. 查看管理者中心左侧导航。

验收点：

- 左侧导航展示“日志管理”入口。
- 点击“日志管理”后进入 `/admin/log-levels` 页面。
- 非超级管理员访问 `/admin/log-levels` 会被前端路由拦截回首页。

### 2.2 Java 后端日志级别动态调整

验收步骤：

1. 进入“管理者中心 / 日志管理”页面。
2. 查看“Java 后端”卡片当前级别。
3. 选择 `DEBUG` 或 `INFO` 等日志级别。
4. 点击“保存级别”。

验收点：

- 页面展示 Java 后端当前日志级别。
- 保存后提示“日志级别已保存”。
- 不重启 Java 后端，后续 Java 后端日志输出按新级别生效。
- 后端接口为 `/api/v1/admin/log-levels/backend`，仅超级管理员可调用。

### 2.3 Python AI 服务日志级别动态调整

验收步骤：

1. 确认 ai-service 已启动，且 `AI_SERVICE_TOKEN` 与 Java 后端 `AI_SERVICE_TOKEN` 一致。
2. 进入“管理者中心 / 日志管理”页面。
3. 查看“Python AI 服务”卡片当前级别。
4. 选择目标日志级别并保存。

验收点：

- AI 服务可达时，页面展示当前日志级别并允许保存。
- 保存后不重启 ai-service，AI 服务后续日志输出按新级别生效。
- AI 服务不可达或内部 Token 不一致时，页面显示“不可用”，并禁用保存按钮。
- 前端只调用 Java 后端接口，不直接访问 AI 服务内部接口。

### 2.4 权限和异常场景

验收步骤：

1. 使用普通用户或未登录状态访问日志管理接口。
2. 使用超级管理员传入不支持的日志级别。
3. 停止 ai-service 后刷新日志管理页面。

验收点：

- 普通用户或游客不能调整日志级别。
- 不支持的日志级别返回中文参数错误提示。
- ai-service 不可用时不影响 Java 后端日志级别查询和设置。
