## 2. 前端页面和功能验收

### 2.1 公开页面访问

验收步骤：

1. 游客访问 `http://localhost:5173/`。
2. 点击“路线和资料”和“建议评论区”。

验收点：

- 根路径默认进入 `/learning-roadmap`。
- 学习路线页面和建议评论区可正常访问。
- 页面不要求登录，不出现空白页或接口报错。

### 2.2 注册和登录

验收步骤：

1. 点击顶部“注册”，输入合法用户名、密码、昵称、邮箱后提交。
2. 退出登录后点击顶部“登录”，输入正确用户名和密码后提交。
3. 分别尝试重复用户名、重复昵称、重复邮箱和错误密码场景。

验收点：

- 注册成功后自动登录，顶部展示当前用户昵称或用户名。
- 登录成功后弹窗关闭，本地存储存在 `ai_learn_access_token`。
- 数据库 `users.password_hash` 保存哈希值，不等于明文密码。
- 昵称和邮箱为必填项，重复注册和错误密码展示明确中文错误提示。

### 2.3 登录态恢复和自动续期

验收步骤：

1. 登录成功后刷新浏览器。
2. 观察顶部用户区，并在网络面板查看 `/users/me` 请求。
3. 持续访问需要后端接口的页面。

验收点：

- 刷新后仍展示当前用户信息，前端通过 `/users/me` 恢复登录态。
- 携带有效 token 调用接口后，可从响应头 `X-Refresh-Token` 获取新 token 并覆盖本地 token。
- token 无效或过期时，前端清理登录态并恢复游客状态。

### 2.4 受保护页面访问控制

验收步骤：

1. 未登录状态访问“热门面经”“AI智能刷题”和 `/profile`。
2. 登录成功后再次访问上述页面。

验收点：

- 未登录时展示中文登录引导，可继续打开登录或注册弹窗。
- 登录后可访问热门面经、AI智能刷题和个人中心。
- 个人中心展示头像或默认头像、用户名、昵称、邮箱、注册时间、经验值、等级名称和段位信息。
- 个人中心不展示头像上传、资料编辑等真实提交入口。

### 2.5 退出登录

验收步骤：

1. 登录后点击顶部用户区。
2. 点击“退出登录”。
3. 再次访问受保护页面。

验收点：

- 顶部恢复为游客登录/注册入口。
- 本地 token 和用户信息被清理。
- 访问受保护页面时重新展示登录引导。
