## 2. 前端页面和功能验收

### 2.1 管理者中心系统题库管理

验收步骤：

1. 登录超级管理员账号，进入右上角“管理者中心”。
2. 打开“系统题库管理”菜单。
3. 使用关键词、分类筛选系统题库。
4. 点击“新增题目”，填写题目、分类、参考答案、重要性评分和真实面试出现次数，`code` 可留空。
5. 编辑刚新增的题目，再删除该题目。
6. 点击“下载CSV模板”，按模板补充数据后使用“上传CSV”导入。

验收点：

- 页面左侧功能栏更窄，主功能区域展示面积更大。
- 系统题库表格展示题目编码、分类、题目、重要性评分、真实面试出现次数和更新时间。
- `code` 留空新增时，后端自动生成题目编码。
- CSV 模板包含 `code,question,question_type,standard_answer,importance_score,occurrence_count` 字段。
- CSV 上传成功后提示新增和更新数量。
- 普通用户不能进入管理者中心，也不能调用系统题库管理接口。

### 2.2 AI 智能刷题聊天页

验收步骤：

1. 使用普通用户登录，进入“AI智能刷题”。
2. 不选择分类，点击“开始刷题”，确认默认从全部分类抽题。
3. 多选一个或多个分类，点击“下一题”，确认按所选分类抽题。
4. 在出题阶段输入“请给我出一道 RAG 类型的题”，确认可以语言出题。
5. 在答题阶段输入答案并发送。
6. 评分后继续输入本题相关追问，确认页面返回本题学习讨论。
7. 点击“重新回答”，确认聊天区清空并重新展示当前题。
8. 点击“下一题”，确认聊天区清空并展示新题。

验收点：

- 页面是聊天式布局，左侧为分类和成长概览，右侧为消息窗口。
- 题目卡片展示编码、分类、重要性、历史最高分、已答次数和真实面试出现次数。
- 提交答案后展示评分、是否基本正确、优化建议、命中点、缺失点、参考答案和经验变化。
- 本次分数小于等于历史最高分时，经验值不增加。
- 评分后可以继续围绕本题讨论，不需要保存聊天记录。
- 明显无关内容会收到温馨提示，不能把刷题入口当作通用聊天。

### 2.3 旧功能下线验收

验收步骤：

1. 登录任意用户，打开右上角用户菜单。
2. 进入个人中心。
3. 手动访问 `/my-questions`。
4. 如使用接口工具调用 `/api/v1/my-questions`、`/api/v1/answer-records/me`、`/api/v1/learning-analysis/me`。

验收点：

- 用户菜单不再展示“我的题库”。
- 个人中心不再展示“我的答题记录”和“薄弱点分析”。
- `/my-questions` 不再作为有效前端业务路由。
- 个人题库、答题记录和薄弱点分析接口不再作为有效业务接口提供。

### 2.4 数据与中间件验收

验收步骤：

1. 启动后端，确认 Flyway 执行到 `V11__system_question_bank_and_practice_summary.sql`。
2. 在 MySQL 执行 `DESC questions;`。
3. 在 MySQL 执行 `DESC user_question_stats;` 和 `DESC user_practice_sessions;`。
4. 完成一次 AI 智能刷题评分后，查询 `user_question_stats`。
5. 确认 Qdrant 和 ai-service 可启动，调用 AI 刷题评分链路。

验收点：

- `questions` 表仅保留系统题库核心字段，不再包含 `title`、`content`、`difficulty`、`tags`、`analysis`、`owner_user_id`、`source_type` 等历史字段。
- `user_question_stats` 只保存题目编码维度的答题次数、最高分和最近得分。
- `user_practice_sessions` 只保存当前刷题状态，不保存聊天明细。
- 不新增完整聊天记录表。
- AI 服务 `/internal/v1/practice/answer/grade` 可返回结构化评分；服务不可用时后端本地规则兜底。
