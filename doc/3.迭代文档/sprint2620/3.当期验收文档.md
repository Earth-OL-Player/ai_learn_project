## 2. 前端页面和功能验收

### 2.1 勋章范围与个人中心展示

验收步骤：

1. 启动后端，确认 Flyway 执行到 `V16`。
2. 登录系统并进入“个人中心”。
3. 查看“徽章墙”中的入门类、坚持类、隐藏/稀有类分区。
4. 使用数据库查询 `badges` 表确认勋章定义。

验收点：

- `badges` 表只保留本期 11 个勋章：初次启程、十题小成、百题修炼、大成圆满、三日不辍、月度坚持者、百日成神、深夜修行者、清晨启动者、周末不摆烂、问到底。
- 个人中心入门类和坚持类未获得时置灰展示，获得后点亮展示。
- 隐藏/稀有类未获得时不展示；获得后才展示并点亮。
- 页面不展示高分选手、RAG 初体验、Agent 探索者等旧勋章。

### 2.2 刷题评分后发放勋章

验收步骤：

1. 登录系统并进入“AI 智能刷题”。
2. 点击“开始”抽取一道题。
3. 输入答案并发送，等待评分完成。
4. 观察页面是否弹出新勋章提示。
5. 进入个人中心刷新成长概览。

验收点：

- 首次完成刷题评分后获得“初次启程”。
- 累计完成 10、100、300 次刷题评分后分别获得“十题小成”“百题修炼”“大成圆满”。
- 晚上 22:00 后完成评分可获得“深夜修行者”；早上 6:00-8:00 完成评分可获得“清晨启动者”；周六或周日完成评分可获得“周末不摆烂”。
- 新勋章只发放一次，再次满足条件不会重复写入 `user_badges`。
- 成长明细中可看到“获得徽章：xxx”事件。

### 2.3 总学习天数勋章

验收步骤：

1. 准备一个已有多天刷题记录的测试账号，或在本地测试库构造不同自然日的刷题记录。
2. 登录该账号并完成一次新的刷题评分。
3. 刷新个人中心徽章墙和成长数据。

验收点：

- 总学习天数达到 3 天时获得“三日不辍”。
- 总学习天数达到 30 天时获得“月度坚持者”。
- 总学习天数达到 100 天时获得“百日成神”。
- 个人中心指标展示“学习天数”，与总学习天数口径一致。

### 2.4 问到底勋章

验收步骤：

1. 登录系统并进入“AI 智能刷题”。
2. 完成一道题评分，进入本题讨论阶段。
3. 围绕本题连续发送 3 次有效追问。
4. 观察第 3 次追问完成后是否弹出新勋章提示。
5. 查询当前题会话和用户勋章记录。

验收点：

- 当前题评分后连续有效追问次数记录在 `user_practice_sessions.discussion_follow_up_count`。
- 第 3 次有效追问后发放“问到底”。
- 切换下一题、重答本题或重新评分后，追问计数从 0 重新开始。
- “问到底”属于隐藏/稀有类，未获得前个人中心不展示，获得后展示。

### 2.5 后端接口与数据库

验收步骤：

1. 调用 `GET /api/v1/growth/me`。
2. 调用 `POST /api/v1/practice/messages/stream` 完成评分场景。
3. 继续调用 `POST /api/v1/practice/messages/stream` 完成追问场景。
4. 查询 `badges`、`user_badges`、`growth_events`、`user_practice_sessions`。

验收点：

- `BadgeResponse` 返回 `category`、`categoryName`、`hidden`、`acquired`、`acquiredAt` 字段。
- 评分触发的新勋章通过 `grading.newBadges` 返回。
- 追问触发的新勋章通过 `growth.newBadges` 返回。
- `growth_events` 记录 `ANSWER` 和 `BADGE` 事件。
- `user_badges` 通过唯一键保证同一用户同一勋章只记录一次。
