## 2. 前端页面和功能验收

### 2.1 建议区评论流

验收步骤：

1. 启动后端和前端后访问 `/suggestions-comments`。
2. 默认进入“建议区”，观察页面头部、建议总数、最热/最新排序、头像输入框和建议类型按钮。
3. 登录后选择“功能建议、体验优化、问题反馈、内容建议”任一类型，输入纯文字建议并发布。
4. 点击建议点赞按钮，再次点击取消点赞。
5. 分别点击“最热”和“最新”排序。

验收点：

- 页面不再出现建议标题、默认待处理、状态标签和旧左右双卡片布局。
- 建议区展示建议类型、作者名称、`LVX·段位`、正文、时间和点赞数。
- 建议区不展示回复按钮，也不出现父子评论结构。
- 输入表情或 `@`、`＠` 时无法发布，并提示“仅支持纯文字，不能使用表情和艾特”。
- 最热按点赞数倒序，最新按发布时间倒序。

### 2.2 评论区父子评论

验收步骤：

1. 在 `/suggestions-comments` 页面点击“评论区”。
2. 登录后输入纯文字父评论并发布。
3. 点击父评论下的“回复”，输入纯文字子评论并发布。
4. 分别对父评论和子评论点赞、取消点赞。
5. 切换“最热”和“最新”排序。

验收点：

- 评论区展示 B 站风格评论流：标题总数、排序、头像输入框、评论列表。
- 评论作者名称后展示 `LVX·段位`。
- 评论区支持一级子评论，子评论缩进展示；页面不提供孙级评论入口。
- 页面不展示“UP主觉得很赞”“互相关注”“转发到动态”等能力。
- 点赞后数量和高亮状态刷新，再次点击可取消。

### 2.3 游客与登录态

验收步骤：

1. 退出登录后访问 `/suggestions-comments`。
2. 观察建议区和评论区列表是否可公开查看。
3. 尝试聚焦输入框、发布、回复或点赞。

验收点：

- 游客可查看建议和评论列表。
- 游客进行发布、回复、点赞时触发登录引导。
- 登录后头像规则与右上角一致：有头像展示头像，无头像展示昵称或用户名首字。

### 2.4 后端接口与数据库

验收步骤：

1. 确认 Flyway 已执行 `V15__redesign_interaction_comments.sql`。
2. 调用 `GET /api/v1/suggestions?pageNo=1&pageSize=10&sort=hot`。
3. 调用 `GET /api/v1/comments?pageNo=1&pageSize=10&sort=hot`。
4. 登录后调用建议、评论发布接口和点赞接口。
5. 查询 `suggestions`、`comments`、`suggestion_likes`、`comment_likes` 表。

验收点：

- `suggestions` 表不再包含 `title`、`status` 字段，包含 `like_count` 字段。
- `comment_likes` 和 `suggestion_likes` 能记录点赞明细，唯一键避免重复点赞。
- 评论分页只分页父评论，并携带一级子评论列表。
- 响应作者摘要包含等级和段位字段。
