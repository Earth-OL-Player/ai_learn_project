## 1. 项目启动步骤

### 1.1 必要的环境变量和中间件

本期复用 MySQL、用户和 JWT 能力，并新增 `suggestions`、`comments` 两张业务表。

必要中间件：

- MySQL 8.4 LTS，详见 `doc/中间件/MySQL.md`。

必要环境变量：

| 环境变量 | 示例占位符 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | `jdbc:mysql://127.0.0.1:3306/ai_learn?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false` | 本地 MySQL JDBC 地址 |
| `DATABASE_USERNAME` | `ai_learn_user` | 本地业务库账号 |
| `DATABASE_PASSWORD` | `本地业务用户密码占位符` | 本地业务库密码，禁止提交真实值 |
| `SPRING_FLYWAY_ENABLED` | `true` | 启用 Flyway 自动建表 |
| `JWT_SECRET` | `至少32位JWT密钥占位符` | JWT 签名密钥，禁止提交真实值 |
| `JWT_EXPIRES_IN_SECONDS` | `7200` | access token 过期秒数 |
| `VITE_API_BASE_URL` | `http://localhost:8080/api/v1` | 前端访问后端 API 的基础地址 |

数据库初始化验收：

1. 启动后端后确认 Flyway 已执行 `V3__init_interaction_tables.sql`。
2. 在 MySQL 中执行 `SHOW TABLES;`，应看到 `users`、`suggestions`、`comments`。
3. 执行 `DESC suggestions;`，应包含 `title`、`content`、`type`、`status`、`user_id`。
4. 执行 `DESC comments;`，应包含 `content`、`user_id`、`parent_id`、`like_count`。

## 2. 前端页面和功能验收

### 2.1 建议区游客查看与登录引导

验收步骤：

1. 不登录，访问 `http://localhost:5173/suggestions-comments`。
2. 保持默认 `建议区` Tab。
3. 点击提交建议区域的 `去登录` 按钮。

验收点：

- 页面展示清新简约的建议评论区头图、Tab、建议列表和分页器。
- 游客可以看到建议列表；无数据时展示空状态。
- 点击发布入口后弹出“登录后即可使用该功能”的登录引导。
- 建议列表按创建时间倒序展示，包含标题、内容、类型、状态、作者和时间。

### 2.2 登录用户提交建议

验收步骤：

1. 通过页面右上角登录或注册账号。
2. 进入 `建议区` Tab。
3. 输入 2-80 位标题、选择建议类型、输入 5-2000 位建议内容。
4. 点击 `提交建议`。

验收点：

- 提交按钮显示 loading，避免重复点击。
- 提交成功后提示“建议提交成功”。
- 表单标题和内容被清空，并自动刷新第一页。
- 最新列表可看到刚提交的建议，状态展示为“待处理”。
- 标题、类型、内容为空或长度不合法时，前端会阻止提交并显示中文校验提示。

### 2.3 评论区游客查看与登录引导

验收步骤：

1. 不登录或退出登录后，访问 `http://localhost:5173/suggestions-comments`。
2. 切换到 `评论区` Tab。
3. 点击发表评论区域的 `去登录` 按钮。

验收点：

- 游客可以看到评论列表；无数据时展示空状态。
- 评论列表展示头像占位、作者昵称或用户名、发布时间、内容和点赞数。
- 点击发布入口后弹出“登录后即可使用该功能”的登录引导。
- 评论列表按创建时间倒序展示。

### 2.4 登录用户发表评论

验收步骤：

1. 登录后进入 `评论区` Tab。
2. 输入 2-1000 位评论内容。
3. 点击 `发表评论`。

验收点：

- 提交按钮显示 loading，避免重复点击。
- 发布成功后提示“评论发布成功”。
- 评论输入框被清空，并自动刷新第一页。
- 最新列表可看到刚发布的评论，点赞数默认为 0。
- 评论内容为空或长度不合法时，前端会阻止提交并显示中文校验提示。

### 2.5 后端接口联调验收

验收步骤：

1. 游客调用 `GET /api/v1/suggestions?pageNo=1&pageSize=10`。
2. 游客调用 `GET /api/v1/comments?pageNo=1&pageSize=10`。
3. 游客调用 `POST /api/v1/suggestions` 和 `POST /api/v1/comments`。
4. 登录后携带 `Authorization: Bearer <accessToken占位符>` 调用两个 POST 接口。

验收点：

- 两个 GET 接口返回统一分页响应，包含 `records`、`pageNo`、`pageSize`、`total`。
- 游客调用两个 POST 接口返回 `AUTH_UNAUTHORIZED`，提示“登录后即可使用该功能”。
- 登录用户提交建议成功，返回作者摘要不包含密码哈希。
- 登录用户发表评论成功，返回作者摘要不包含密码哈希。
- `pageSize` 大于 100 时，后端最多按 100 条处理。
