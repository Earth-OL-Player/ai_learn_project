# sprint202610 当期设计方案

版本：v1.0  
日期：2026-05-14  
迭代定位：成长体系增强与徽章展示  
对应需求：`doc/3.迭代文档/sprint202610/1.当期需求文档.md`

## 1. 架构说明

成长体系集中放在 `growth` 上下文，答题提交完成后由 `growth` 应用服务计算经验、段位和徽章。

## 2. 数据库迁移

新增或启用表：

```text
badges
user_badges
growth_events
```

- `badges.rule_code` 标识规则。
- `user_badges` 对 `user_id + badge_id` 加唯一约束，避免重复发放。
- `growth_events` 保存经验和徽章流水，供个人中心展示。

## 3. 后端设计

新增服务：

```text
GrowthAwardService
BadgeRuleDomainService
LearningStreakService
```

答题提交流程：

1. 保存答题记录。
2. 计算经验和等级段位。
3. 根据答题记录和历史数据判断徽章。
4. 写入成长流水和用户徽章。
5. 返回本次成长反馈。

## 4. 前端设计

- 个人中心成长概览升级为进度条和段位卡片。
- 新增徽章墙，未获得徽章置灰展示。
- 答题结果页展示本次新获得徽章。

## 5. 验证要求

本项目当前要求禁止新增单元测试代码，本期只整理接口联调和人工验收。

- 首题、高分、连续学习等场景可人工验证徽章发放。
- 重复提交或重复满足规则不会重复插入徽章。
- 个人中心成长墙展示正确。
