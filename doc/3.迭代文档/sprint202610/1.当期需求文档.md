## 1. 当期目标

将基础经验升级为可展示、可持续激励的成长体系，补齐等级、段位、徽章、连续学习和个人中心成长墙。

## 3. 徽章规则

| 徽章 | 条件 |
| --- | --- |
| 初次启程 | 完成第 1 道题 |
| 坚持三天 | 连续学习 3 天 |
| 七日修炼 | 连续学习 7 天 |
| 高分选手 | 单题得分达到 90 分以上 |
| 查漏补缺 | 低分题复刷后提升 20 分以上 |
| RAG 初体验 | RAG 相关题目完成 10 道 |
| Agent 探索者 | Agent 相关题目完成 10 道 |

## 4. 验收标准

- 用户完成首题后获得“初次启程”徽章。
- 单题 90 分以上后获得“高分选手”徽章。
- 已获得徽章不会重复发放。
- 个人中心可以看到经验进度、等级、段位和徽章墙。
