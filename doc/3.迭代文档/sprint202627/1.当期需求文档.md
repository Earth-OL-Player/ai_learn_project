# sprint202627 当期需求文档

版本：v1.0  
日期：2026-05-24  
迭代定位：高级模型授权、兑换码权益和管理员模型配置闭环

## 1. 背景

当前平台已经具备 AI 智能刷题、题库管理、用户成长和管理者中心能力，但模型能力仍主要依赖统一的默认配置，用户无法通过兑换码获得高级模型或超级模型权益，管理员也无法在页面维护不同等级模型的调用配置。

本迭代目标是补齐付费权益主链路：让用户可以清晰看到当前刷题模型、剩余天数和授权入口；让超级管理员可以生成、维护和导出兑换码；让用户在个人中心兑换权益；让 AI 智能刷题真实按用户当前权益选择模型配置。

## 3. 非功能要求

1. 本迭代需要新增 MySQL 表结构，必须通过新的 Flyway migration 完成，不修改历史 migration。
2. 不新增 Redis、Qdrant 或其他中间件依赖；如新增环境变量或配置项，需要同步更新 `doc/中间件/` 文档。
3. 不编写单元测试代码，验收阶段使用后端构建、前端构建和人工页面验收。
4. 真实密码、Token、模型 Key、生产授权地址和生产连接地址不得提交仓库，示例配置必须使用占位符。
5. 兑换码、模型配置和权益状态属于核心付费能力，后端需要保证低等级权益不能覆盖或降级高等级权益。
6. 前端 UI 保持清新、简约、大气，兑换码和模型配置页面优先服务高频管理操作。
