# sprint2621 当期需求文档

版本：v1.0  
日期：2026-05-18  
迭代定位：个人中心瘦身、认证弹框视觉升级、管理员用户与题库高危操作补齐、平台品牌升级

## 1. 背景

当前 AI 学习平台已具备路线资料、建议评论、热门题库、AI 智能刷题、个人中心和管理者中心等核心模块。本迭代围绕实际运营和展示体验补齐以下能力：

1. 个人中心不再展示成长明细，减少冗余信息，但必须保留徽章墙、等级、段位和成长概览。
2. 登录、注册弹框视觉观感较弱，需要统一升级为清新、简约、大气且兼容常见屏幕的样式。
3. 管理者中心需要具备用户管理能力，并可配置系统最大用户数，作为本地和服务器容量保护手段。
4. 系统题库管理需要提供高危但明确的一键清空能力，真实清空题库数据。
5. 平台品牌从“AI应用开发学习平台”升级为“AI AGENT学习平台”，并在合适位置展示作者信息：`Author:地球OL初级玩家`。

## 3. 非功能要求

1. 不编写单元测试代码，本迭代仅做功能开发和构建验证。
2. 代码注释和文档统一使用 UTF-8 简体中文。
3. 不提交真实密码、Token、密钥、生产连接地址等敏感信息。
4. 新增 MySQL 表和题库清空能力必须同步更新 `doc/中间件/MySQL.md`。
5. 管理端接口必须复用超级管理员校验，普通用户不可访问。
6. 一键清空题库属于高危操作，前端必须有确认弹框，后端必须限制为超级管理员。
