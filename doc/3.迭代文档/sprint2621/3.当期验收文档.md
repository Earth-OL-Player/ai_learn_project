## 2. 前端页面和功能验收

### 2.1 个人中心成长概览瘦身

验收步骤：

1. 登录任意普通用户或超级管理员账号。
2. 点击右上角用户下拉菜单，进入“个人中心”。
3. 查看成长概览区域和徽章墙。

验收点：

- 页面不再展示“成长明细”模块。
- 成长概览仍展示角色卡、当前总经验、累计答题、平均得分、学习天数和修炼进度。
- 徽章墙仍可按入门类、坚持类、隐藏/稀有类展示；隐藏稀有徽章未获得时不提前曝光。
- 调用 `/api/v1/growth/me` 时响应中不再包含 `recentEvents` 字段。

### 2.2 登录注册弹框 UI

验收步骤：

1. 退出登录或使用无登录态浏览器访问系统。
2. 点击顶部“登录”按钮。
3. 关闭后再点击顶部“注册”按钮。
4. 分别验证必填、格式错误和正常提交场景。

验收点：

- 登录、注册弹框展示浅色渐变头图、品牌徽标、圆角输入框和圆角按钮，整体清新简约。
- 登录字段仍为用户名和密码；注册字段仍为用户名、密码、昵称、邮箱。
- 原有前端校验和后端错误提示不丢失。
- 窄屏下注册弹框双列表单可自动变为单列展示。

### 2.3 管理员中心用户管理

验收步骤：

1. 使用超级管理员账号登录。
2. 点击右上角用户下拉菜单进入“管理者中心”。
3. 进入“用户管理”菜单。
4. 使用关键词查询用户。
5. 点击“新增用户”，填写用户名、密码、昵称、邮箱和权限后保存。
6. 对新增用户执行编辑和删除操作。

验收点：

- 用户管理页面展示用户列表、邮箱、角色、经验、注册时间和操作按钮。
- 新增用户必须校验用户名、密码、昵称和邮箱。
- 编辑用户时密码可为空，表示不修改原密码。
- 删除用户为逻辑删除，删除后列表不再展示该用户。
- 后端禁止删除当前登录管理员，禁止取消当前登录管理员自己的超级管理员权限。

### 2.4 最大用户数限制

验收步骤：

1. 使用超级管理员账号进入“管理者中心 > 用户管理”。
2. 查看最大用户数限制卡片。
3. 将最大用户数设置为当前用户数并保存。
4. 退出登录或打开无登录态浏览器，尝试注册新用户。
5. 再将最大用户数调大，重新注册。

验收点：

- 页面展示 `当前用户数 / 最大用户数`。
- 保存后 `system_settings.MAX_USERS` 同步更新。
- 当前用户数达到上限时，注册失败并提示：`当前系统用户数量已达上限，等待管理员升级服务器并扩容`。
- 最大用户数调大后，新用户可正常注册。

### 2.5 系统题库一键清空

验收步骤：

1. 使用超级管理员账号进入“管理者中心 > 系统题库管理”。
2. 点击“一键清除当前题库”。
3. 在确认弹框中点击“确认清空”。
4. 查看题库列表和数据库 `questions` 表。
5. 如需继续验收刷题，可重新上传 CSV 恢复题库。

验收点：

- 前端二次确认文案明确提示会真实清空题库并重置自增ID。
- 后端调用 `TRUNCATE TABLE questions` 真实清空题库主表。
- 清空后题库列表为空，题目分类同步刷新为空。
- 用户题目汇总被清理，当前刷题状态被重置，避免旧题编码残留。

### 2.6 品牌升级

验收步骤：

1. 打开任意前端页面。
2. 查看顶部品牌区域和浏览器标题。
3. 打开登录或注册弹框。

验收点：

- 顶部品牌名称为“AI AGENT学习平台”。
- 顶部品牌区域展示 `Author:地球OL初级玩家`。
- 浏览器标题为“AI AGENT学习平台”。
- 登录、注册弹框文案使用“AI AGENT学习平台”。
