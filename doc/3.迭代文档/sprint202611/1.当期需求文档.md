# sprint202611 当期需求文档

版本：v1.0  
日期：2026-05-16  
迭代定位：超级管理员入口与管理者中心占位  
前置依赖：sprint202601 - sprint202610

## 1. 当期目标

在现有普通用户能力不变的基础上，为平台引入超级管理员标识，并在前端为超级管理员开放管理者中心入口。本迭代先完成权限身份识别、入口展示、管理者中心框架和系统题库管理空白页，为后续后台管理能力预留承载页面。

| 编号 | 需求项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| S11-R01 | 用户超级管理员标识 | 用户表新增超级管理员字段，默认注册用户为普通用户 | P0 |
| S11-R02 | 身份返回 | 登录、注册和当前用户接口返回超级管理员标识 | P0 |

## 3. 业务规则

1. 平台注册用户默认是普通用户，不能通过前端注册、登录或页面操作把自己设置为超级管理员。
2. 超级管理员只能由后台开发者通过数据库字段维护，平台前端不提供开关或设置入口。
3. 超级管理员保留普通用户已有能力，可继续访问个人中心、我的题库、热门面经和 AI 智能刷题等功能。
4. 仅超级管理员可在右上角用户下拉菜单看到“管理者中心”入口。
5. 非超级管理员即使手工输入管理者中心路由，也不能进入管理页面。
6. 本迭代系统题库管理只做导航和空白页，不实现题目新增、编辑、删除和导入等后台操作。

## 4. 数据要求

| 字段 | 所属表 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `super_admin` | `users` | `0` | `1` 表示超级管理员，`0` 表示普通用户 |

后台开发者本地验证可使用以下占位 SQL，把指定用户临时调整为超级管理员：

```sql
UPDATE users SET super_admin = 1 WHERE username = '本地用户名占位符';
```

注意：真实用户名只能使用本地或测试环境数据，禁止在文档中写入生产账号。

## 5. 验收标准

- 新注册用户登录后为普通用户，不展示“管理者中心”。
- 数据库把用户 `super_admin` 改为 `1` 后，重新登录或刷新当前用户信息可展示“管理者中心”。
- 超级管理员点击“管理者中心”后进入管理者中心页面。
- 管理者中心左侧存在“系统题库管理”菜单。
- 系统题库管理页面为当前迭代空白占位页，不出现未实现操作按钮。
- 普通用户直接访问管理者中心路由时会被拦截并回到学习路线页面。
