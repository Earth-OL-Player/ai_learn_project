# sprint202611 当期设计方案

版本：v1.0  
日期：2026-05-16  
迭代定位：超级管理员入口与管理者中心占位  
对应需求：`doc/3.迭代文档/sprint202611/1.当期需求文档.md`

## 1. 架构说明

本迭代采用最小闭环设计：后端只负责持久化和返回超级管理员身份，前端根据当前用户摘要控制管理者中心入口和路由访问。系统题库管理当前是空白占位页，不新增题库管理接口，避免提前引入未验收的后台操作能力。

## 2. 数据库设计

新增 Flyway migration：

```text
V10__add_user_super_admin_flag.sql
```

变更内容：

```sql
ALTER TABLE users
    ADD COLUMN super_admin TINYINT NOT NULL DEFAULT 0 COMMENT '是否超级管理员';
```

设计说明：

- 使用 `TINYINT` 兼容 MySQL 布尔存储习惯。
- 默认值为 `0`，保证历史用户和新注册用户均为普通用户。
- 不新增前端配置项、环境变量或启动参数。

## 3. 后端设计

涉及对象：

| 文件 | 设计 |
| --- | --- |
| `User` | 增加 `superAdmin` 字段及访问方法 |
| `UserMapper` | 查询和新增用户时映射 `super_admin` 字段 |
| `AuthService` | 注册用户显式设置 `superAdmin=false` |
| `UserSummary` | 当前用户摘要增加 `superAdmin` |
| `UserSummaryConverter` | 将数据库字段转换给前端 |

接口影响：

- `POST /api/v1/auth/register` 响应的 `user` 增加 `superAdmin`。
- `POST /api/v1/auth/login` 响应的 `user` 增加 `superAdmin`。
- `GET /api/v1/users/me` 响应增加 `superAdmin`。

## 4. 前端设计

新增页面结构：

```text
/admin
└── /admin/system-question-bank
```

涉及对象：

| 文件 | 设计 |
| --- | --- |
| `api/user.ts` | 当前用户类型增加 `superAdmin` |
| `stores/auth.ts` | 增加 `isSuperAdmin` 计算属性 |
| `layout/AppLayout.vue` | 超级管理员用户下拉菜单展示“管理者中心” |
| `router/index.ts` | 新增管理者中心路由和超级管理员前置守卫 |
| `pages/admin/AdminCenterPage.vue` | 管理者中心左侧导航框架 |
| `pages/admin/SystemQuestionBankManagePage.vue` | 系统题库管理空白占位页 |
| `styles/global.scss` | 补充管理者中心清新简约页面样式 |

路由守卫规则：

1. 未登录访问管理者中心时复用登录引导。
2. 已登录但不是超级管理员时跳转学习路线页面。
3. 超级管理员访问 `/admin` 时默认进入 `/admin/system-question-bank`。

本项目当前要求禁止新增单元测试代码，本期只执行构建、接口联调和人工验收。
