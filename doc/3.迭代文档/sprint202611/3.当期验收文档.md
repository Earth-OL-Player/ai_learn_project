## 2. 前端页面和功能验收

### 2.1 普通用户默认无管理者中心

验收步骤：

1. 启动完整本地环境，访问前端首页。
2. 注册一个新用户并保持登录。
3. 点击右上角用户头像和昵称区域，展开用户下拉菜单。

验收点：

- 新注册用户可以正常使用普通用户功能。
- 用户下拉菜单包含“个人中心”“我的题库”“退出登录”。
- 用户下拉菜单不展示“管理者中心”。
- 数据库 `users.super_admin` 对该用户默认为 `0`。

### 2.2 超级管理员展示管理者中心入口

验收步骤：

1. 在本地测试库把指定用户设置为超级管理员：

   ```sql
   UPDATE users SET super_admin = 1 WHERE username = '本地用户名占位符';
   ```

2. 重新登录该用户，或刷新页面后重新获取当前用户信息。
3. 点击右上角用户头像和昵称区域，展开用户下拉菜单。

验收点：

- 用户下拉菜单在“个人中心”下方展示“管理者中心”。
- “管理者中心”只对 `super_admin=1` 的用户展示。
- 不存在通过前端页面把普通用户升级为超级管理员的按钮或入口。

### 2.3 管理者中心和系统题库管理空白页

验收步骤：

1. 使用超级管理员账号点击“管理者中心”。
2. 观察页面左侧管理菜单。
3. 点击或确认当前选中“系统题库管理”。

验收点：

- 页面进入 `/admin/system-question-bank`。
- 管理者中心左侧展示“系统题库管理”菜单。
- 右侧页面展示“系统题库管理”标题和空白占位内容。
- 当前页面不出现新增、编辑、删除、导入等未实现操作按钮。

### 2.4 普通用户直接访问管理路由拦截

验收步骤：

1. 使用普通用户登录。
2. 在浏览器地址栏直接访问 `/admin/system-question-bank`。

验收点：

- 普通用户不会进入管理者中心页面。
- 页面会被前端路由守卫引导回学习路线页面。
