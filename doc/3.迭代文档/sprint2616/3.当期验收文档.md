## 2. 前端页面和功能验收

### 2.1 重答本题清理上下文

验收步骤：

1. 登录系统，进入“AI 智能刷题”页面。
2. 点击“开始”抽取一道题，并提交一段答案完成评分。
3. 在讨论阶段输入“我刚刚回答的答案是什么？”，确认系统可围绕刚才答案回复。
4. 点击“重答本题”。
5. 不提交新答案前，观察聊天面板和题目卡片。
6. 提交一段不同的新答案后，再次追问“我刚刚回答的答案是什么？”。

验收点：

- 点击“重答本题”后，旧聊天记录被清空，只保留重新作答提示和当前题题目卡片。
- 后端当前题最近答案被清空，新一轮讨论不应引用重答前的旧答案。
- 新答案评分后，追问应围绕最新提交答案回复。

### 2.2 答题上下文记忆

验收步骤：

1. 配置真实模型服务，确保 `AI_SERVICE_ENABLED=true` 且 `AI_GRADING_MODEL` 不是 `LOCAL_RULE`。
2. 抽取一道题，提交包含明显关键词的答案。
3. 评分完成后，在讨论阶段输入“我刚刚回答的答案是什么？”或“结合我刚才答案帮我优化”。

验收点：

- AI 回复能引用当前题最近一次答案，而不是回答其他不相干内容。
- AI 回复能结合题目、参考答案和用户答案给出优化建议。
- Python AI 服务日志可看到讨论请求正常返回，但不得打印完整用户答案和真实密钥。

### 2.3 经验变化悬浮详情

验收步骤：

1. 首次回答一道未答过的题并完成评分。
2. 将鼠标移动到评分卡片中的“+X 经验”或“经验不变”标识上。
3. 重答同题，分别提交更高分和未超过历史最高分的答案。
4. 再次悬浮查看经验变化详情。

验收点：

- 首次回答展示“首次回答得了 X 分，新增 X 经验”。
- 突破历史最高分时展示“比上次回答多拿了 X 分，并突破历史最高分新增 Y 经验”。
- 未突破历史最高分时展示“未能突破上次最高分 X 分，本次经验不变”。
- tooltip 样式轻量，不遮挡评分主体内容。

### 2.4 大模型无关内容拦截

验收步骤：

1. 在答题阶段输入“今天天气怎么样”。
2. 在讨论阶段输入“帮我做饭”。
3. 在讨论阶段输入“请解释一下这道题里的 RAG 召回和重排”。
4. 可选：关闭真实模型配置，再重复明显无关内容。

验收点：

- 配置真实模型时，相关性判断优先由 AI 服务 `/internal/v1/practice/relevance` 完成。
- 明显无关内容被拦截，并提示围绕当前题作答或技术讨论。
- 技术讨论内容不被误拦截。
- 模型不可用时，本地兜底仍能拦截天气、股票、做饭、笑话等明显无关内容。

### 2.5 Markdown 渲染

验收步骤：

1. 在讨论阶段输入“请用 Markdown 标题、加粗和列表解释这道题”。
2. 等待 AI 返回包含 `# 标题`、`**加粗**`、列表和行内代码的内容。

验收点：

- 前端聊天气泡可正确渲染标题、加粗、列表、段落和行内代码。
- 原始 HTML 不被执行，页面不出现脚本注入风险。
- 样式与现有聊天 UI 保持清新简约。

### 2.6 流式输出

验收步骤：

1. 在刷题页面输入框发送任意有效答案或讨论问题。
2. 观察助手气泡输出过程。
3. 评分场景下等待最终评分卡片展示。
4. 讨论场景下等待最终文本完整展示。

验收点：

- 发送后立即出现“AI 正在思考中...”占位。
- 讨论阶段助手回复随模型 token 逐段展示，而不是等待完整响应后一次性出现。
- 后端日志可看到 `practice_discuss_stream` 场景调用；浏览器 Network 中 `/api/v1/practice/messages/stream` 持续接收 `message` 事件。
- 最终结果到达后，题目卡片、评分卡片、成长信息和阶段状态正常补齐。
- 出题和评分阶段因需要先完成题目选择或结构化评分，允许在业务结果完成后再展示提示文案和卡片。
- 流式异常时前端有错误提示，并移除未完成的助手占位消息。

### 2.7 MySQL 字段与文档验收

验收步骤：

1. 启动后端并确认 Flyway 执行成功。
2. 在 MySQL 执行以下 SQL：

```sql
DESC user_practice_sessions;
SELECT user_id, question_code, phase, last_score, LEFT(last_answer_text, 80) AS last_answer_preview
FROM user_practice_sessions
WHERE user_id = 用户ID占位符;
```

3. 查看 `doc/中间件/MySQL.md` 和 `doc/中间件/AI模型服务.md`。

验收点：

- `user_practice_sessions` 存在 `last_answer_text` 字段。
- 评分后该字段保存当前题最近一次答案片段；重答或下一题后字段清空。
- MySQL 文档说明了字段用途、验证 SQL 和部署注意事项。
- AI 模型服务文档说明了 `lastUserAnswer` 和 `/internal/v1/practice/relevance`。
