# 中间件文档索引

版本：v1.2  
日期：2026-05-18

本目录记录项目依赖的中间件。只要新增或修改 MySQL、Redis、Qdrant、对象存储、消息队列等依赖，就必须同步更新对应文档和示例配置。

## 1. 当前文档

| 文档 | 中间件 | 支持场景 |
| --- | --- | --- |
| `MySQL.md` | MySQL 8.4 LTS | 本地业务库搭建、后端连接配置、Flyway 验证、生产备份和安全配置 |
| `Redis.md` | Redis Open Source 8.x | 后续缓存、限流、验证码、登录态辅助的预留说明；当前运行代码尚未接入 Redis |
| `Qdrant.md` | Qdrant 1.x | 启用 RAG 入库/检索时的本地向量库搭建、AI 服务配置、验证和生产数据持久化 |

## 2. 文档维护要求

- 示例配置只写占位符，不写真实密码、Token、密钥或生产连接地址。
- 新增环境变量、配置字段或启动参数时，同步更新对应中间件文档。
- 本地开发、联调验证、生产部署的差异要写清楚。
- 如果后续引入对象存储、消息队列、搜索引擎等中间件，需要在本目录新增独立说明文档，并更新本索引。

## 3. 与架构的对应关系

- MySQL：由 `ai-learn-backend` 访问，保存业务主数据。
- Redis：当前未接入运行代码，仅作为后续缓存、限流和短期状态能力预留。
- Qdrant：由 `ai-service` 访问，保存 RAG 所需向量索引。

浏览器不直接访问任何中间件；AI 服务也不直接写入 MySQL 核心业务表。
