# 快速版本更新上线方案

版本：v1.5 · 更新日期：2026-10-05

用于当前 Windows 本机打包、腾讯云服务器更新。按以下顺序执行：**维护配置 → 构建 → 上传 → 部署 → 验证**。

## 1. 完整生产配置

在本机维护以下两个文件，已填入本期配置。生产连接值来自首次部署文档，发布前在本机核对即可；以后只修改这两个文件，上传后整文件覆盖服务器配置。

| 本机配置文件 | 服务器覆盖目标 |
| --- | --- |
| [.local/production/backend.env](../../.local/production/backend.env) | `/etc/ai-learn/backend.env` |
| [.local/production/ai-service.env](../../.local/production/ai-service.env) | `/etc/ai-learn/ai-service.env` |

两端 `AI_SERVICE_TOKEN` 相同。后端包含数据库、JWT、限流和助手参数；Python 默认模型为 `gpt-6-luna`，模型调用超时 60 秒、助手执行预算 120 秒。实际模型沿用线上 `model_configs` 的用户档位配置，保留现有用户与模型数据，不执行 BASIC 更新 SQL。新表由 Flyway 自动迁移，已执行版本不会重复执行。

## 2. 本地构建和打包

在项目根目录 PowerShell 执行。使用 `.local/dev.config.json` 中的本机工具路径，先停止本地服务释放 JAR 和前端依赖占用，数据库数据保留。若后端另由 IDE 启动，先在 IDE 中停止。

```powershell
$ErrorActionPreference = "Stop"
function Check([string]$Step) {
    if ($LASTEXITCODE -ne 0) { throw "$Step 失败，退出码：$LASTEXITCODE" }
}

$Name = "ai-learn-$(Get-Date -Format yyyyMMddHHmmss)"
$Release = ".\release\$Name"
New-Item -ItemType Directory -Force "$Release\ai-learn-web", ".\release\logs" | Out-Null
Start-Transcript -Path ".\release\logs\build-$Name.log" | Out-Null
try {
    & powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-dev.ps1 -Action Stop
    Check "停止本地服务"

    $Runtime = Get-Content .\.local\dev.config.json -Raw | ConvertFrom-Json
    $env:JAVA_HOME = $Runtime.javaHome
    $NodeDir = Split-Path $Runtime.node -Parent
    $env:Path = "$($env:JAVA_HOME)\bin;$NodeDir;$env:Path"
    $Npm = Join-Path $NodeDir "npm.cmd"
    $Python = (Resolve-Path .\ai-service\.venv\Scripts\python.exe).Path

    & $Runtime.maven -f .\ai-learn-backend\pom.xml -DskipTests clean package
    Check "后端构建"
    & $Npm --prefix .\ai-learn-web ci
    Check "前端依赖安装"
    $env:VITE_API_BASE_URL = "/api/v1"
    & $Npm --prefix .\ai-learn-web run build
    Check "前端构建"

    Push-Location .\ai-service
    try {
        & $Python -m app.assistant.build_knowledge
        Check "知识索引生成"
    } finally { Pop-Location }

    Copy-Item .\ai-learn-backend\target\ai-learn-backend-0.0.1-SNAPSHOT.jar "$Release\ai-learn-backend.jar"
    Copy-Item .\ai-learn-web\dist\* "$Release\ai-learn-web" -Recurse
    robocopy .\ai-service "$Release\ai-service" /E /XD .venv __pycache__ /XF .env /R:2 /W:1 /NFL /NDL /NJH /NJS
    if ($LASTEXITCODE -gt 7) { throw "AI 源码复制失败：$LASTEXITCODE" }
    tar -czf ".\release\$Name.tar.gz" -C .\release $Name
    Check "压缩发布包"
    Write-Host "发布包：.\release\$Name.tar.gz"
} finally {
    Remove-Item Env:\VITE_API_BASE_URL -ErrorAction SilentlyContinue
    Stop-Transcript | Out-Null
}
```

发布包包含 JAR、前端静态文件和 Python 源码；完整生产配置单独上传。

## 3. 上传发布包和完整配置

仍在本地项目根目录执行。选择最新发布包，上传两个完整配置文件。

```powershell
$ErrorActionPreference = "Stop"
function Check([string]$Step) {
    if ($LASTEXITCODE -ne 0) { throw "$Step 失败，退出码：$LASTEXITCODE" }
}
$Server = "root@159.75.111.145"
$Package = Get-ChildItem .\release\ai-learn-*.tar.gz | Sort-Object LastWriteTime -Descending | Select-Object -First 1
if (-not $Package) { throw "请先构建发布包" }
foreach ($File in @("backend.env", "ai-service.env")) {
    if (-not (Test-Path ".\.local\production\$File")) { throw "缺少完整生产配置：$File" }
}

scp $Package.FullName "${Server}:/tmp/"
Check "上传发布包"
ssh $Server "mkdir -p /tmp/ai-learn-config && chmod 700 /tmp/ai-learn-config"
Check "准备配置目录"
scp .\.local\production\backend.env .\.local\production\ai-service.env "${Server}:/tmp/ai-learn-config/"
Check "上传完整配置"
ssh $Server "printf '%s\n' '$($Package.Name)' > /tmp/ai-learn-latest-package.txt"
Check "记录发布包"
```

## 4. 服务器部署

登录服务器：`ssh root@159.75.111.145`。

### 更新代码和配置

```bash
set -euo pipefail
# 是否备份旧代码与配置：0=跳过，1=备份（不包含数据库）。
ENABLE_BACKUP=0
# 是否安装 Python AI 依赖：0=沿用已有依赖，1=按 requirements.txt 安装。
INSTALL_AI_DEPS=1
PACKAGE=$(cat /tmp/ai-learn-latest-package.txt)
NAME=${PACKAGE%.tar.gz}
WORK=/tmp/$NAME
RECORD=/opt/ai-learn/releases/$NAME
mkdir -p "$RECORD"
exec > >(tee -a "$RECORD/deploy.log") 2>&1
tar -xzf "/tmp/$PACKAGE" -C /tmp
# 缺少发布文件时立即退出，避免 rsync 清空线上资源。
test -f "$WORK/ai-learn-backend.jar"
test -f "$WORK/ai-learn-web/index.html"
test -f "$WORK/ai-service/app/main.py"
test -f /tmp/ai-learn-config/backend.env
test -f /tmp/ai-learn-config/ai-service.env
/www/server/nginx/sbin/nginx -t

systemctl stop ai-learn-backend ai-learn-ai
if [ "$ENABLE_BACKUP" = 1 ] && [ ! -d "$RECORD/backup" ]; then
    mkdir -p "$RECORD/backup"
    cp /opt/ai-learn/backend/ai-learn-backend.jar "$RECORD/backup/"
    tar -czf "$RECORD/backup/web.tar.gz" -C /www/wwwroot ai-learn-web
    tar --exclude=.venv --exclude=__pycache__ -czf "$RECORD/backup/ai.tar.gz" -C /opt/ai-learn ai-service
    cp /etc/ai-learn/backend.env /etc/ai-learn/ai-service.env "$RECORD/backup/"
    chmod -R go-rwx "$RECORD/backup"
fi

# 完整覆盖两份生产配置。
install -o root -g ai-learn -m 640 /tmp/ai-learn-config/backend.env /etc/ai-learn/backend.env
install -o root -g ai-learn -m 640 /tmp/ai-learn-config/ai-service.env /etc/ai-learn/ai-service.env
install -o ai-learn -g ai-learn -m 640 "$WORK/ai-learn-backend.jar" /opt/ai-learn/backend/ai-learn-backend.jar
rsync -a --delete "$WORK/ai-learn-web/" /www/wwwroot/ai-learn-web/
chown -R www:www /www/wwwroot/ai-learn-web
find /www/wwwroot/ai-learn-web -type d -exec chmod 755 {} \;
find /www/wwwroot/ai-learn-web -type f -exec chmod 644 {} \;
rsync -a --delete --exclude=.venv --exclude=__pycache__ --exclude=.env "$WORK/ai-service/" /opt/ai-learn/ai-service/
chown -R ai-learn:ai-learn /opt/ai-learn/ai-service

if [ "$INSTALL_AI_DEPS" = 1 ]; then
    sudo -u ai-learn python3.11 -m venv /opt/ai-learn/ai-service/.venv
    sudo -u ai-learn /opt/ai-learn/ai-service/.venv/bin/pip install -r /opt/ai-learn/ai-service/requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple --prefer-binary
fi
systemctl start ai-learn-ai ai-learn-backend
/etc/init.d/nginx reload
rm -f /tmp/ai-learn-config/backend.env /tmp/ai-learn-config/ai-service.env
echo "已发布：$NAME；日志：$RECORD/deploy.log"
```

## 5. 上线验证与回退

等服务启动约 15 秒后，在服务器执行：

```bash
curl -fsS http://127.0.0.1:8000/health
curl -fsS http://127.0.0.1:8080/api/v1/health
curl -fsS http://159.75.111.145/api/v1/health
```

浏览器打开 `http://159.75.111.145`，确认登录、AI 刷题评分、助手“打开评论区”和填写草稿正常，流式反馈逐步显示。服务异常时查看日志：

```bash
journalctl -u ai-learn-backend -u ai-learn-ai -n 100 --no-pager
```

发布时开启了备份，可按以下命令回退代码及配置；数据库数据不回退。将 `NAME` 改成发生问题的发布版本目录名。

```bash
set -euo pipefail
NAME=ai-learn-替换为发布版本号
BACKUP=/opt/ai-learn/releases/$NAME/backup
test -f "$BACKUP/ai-learn-backend.jar"
test -f "$BACKUP/web.tar.gz"
test -f "$BACKUP/ai.tar.gz"
systemctl stop ai-learn-backend ai-learn-ai
install -o ai-learn -g ai-learn -m 640 "$BACKUP/ai-learn-backend.jar" /opt/ai-learn/backend/ai-learn-backend.jar
install -o root -g ai-learn -m 640 "$BACKUP/backend.env" /etc/ai-learn/backend.env
install -o root -g ai-learn -m 640 "$BACKUP/ai-service.env" /etc/ai-learn/ai-service.env
RESTORE=$(mktemp -d /tmp/ai-learn-restore.XXXXXX)
tar -xzf "$BACKUP/web.tar.gz" -C "$RESTORE"
tar -xzf "$BACKUP/ai.tar.gz" -C "$RESTORE"
rsync -a --delete "$RESTORE/ai-learn-web/" /www/wwwroot/ai-learn-web/
rsync -a --delete --exclude=.venv --exclude=.env "$RESTORE/ai-service/" /opt/ai-learn/ai-service/
chown -R www:www /www/wwwroot/ai-learn-web
chown -R ai-learn:ai-learn /opt/ai-learn/ai-service
systemctl start ai-learn-ai ai-learn-backend
```

未开启备份时，使用上一版代码重新构建发布包，并配合对应的本机完整配置重新发布。
