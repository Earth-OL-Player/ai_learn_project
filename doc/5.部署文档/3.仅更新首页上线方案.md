# 仅更新首页 Markdown 到服务器的最简命令

适用文件：`ai-learn-web/src/content/learning-roadmap/首页.md`

> 注意：生产环境当前通过 Nginx 托管 `ai-learn-web/dist` 静态资源。`首页.md` 会在前端构建时被打包进 `dist`，因此只上传源 Markdown 文件不会更新线上页面，必须重新构建前端并替换线上静态资源。

## 1. PowerShell 最简发布命令

在项目根目录执行，服务器地址已按快速上线方案固定为 `root@159.75.111.145`。

```powershell
$Server = "root@159.75.111.145"
npm --prefix .\ai-learn-web run build
ssh $Server "rm -rf /tmp/ai-learn-web-home && mkdir -p /tmp/ai-learn-web-home"
scp -r .\ai-learn-web\dist\* "${Server}:/tmp/ai-learn-web-home/"
ssh $Server "rsync -av --delete /tmp/ai-learn-web-home/ /www/wwwroot/ai-learn-web/ && chown -R www:www /www/wwwroot/ai-learn-web && /www/server/nginx/sbin/nginx -t && /etc/init.d/nginx reload"
```

## 2. 快速验证命令3

```powershell
curl -I https://www.ai-studyhub.cn
```

如果域名暂未启用 HTTPS，可临时改为：

```powershell
curl -I http://159.75.111.145
```

## 3. 仅同步源文件的命令

下面命令只适合把源码同步到服务器留档，不会更新线上页面。

```powershell
$Server = "root@159.75.111.145"
scp .\ai-learn-web\src\content\learning-roadmap\首页.md "${Server}:/opt/ai-learn/source/ai-learn-web/src/content/learning-roadmap/首页.md"
```
