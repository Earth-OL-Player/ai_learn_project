## 1. 背景

`AI 技术`正在以非常夸张的速度发展，最先被改变的，就是`程序员的生产方式`。

以前需要花很久才能完成的需求，现在有了`大模型`、`AI 编程工具`效率会被明显放大。

`传统前后端岗位`不会消失，但“只会写页面、只会写接口”的`竞争力`会越来越弱；

与此同时，`大模型相关工作`的方向，正在变成越来越`真实的机会`。

所以，我更倾向于把它看成一次`重新洗牌`：

- 不是所有人都要去`训练大模型`；
- 不是所有人都要去研究`算法论文`；
- 但普通开发者非常有机会学会“怎么把大模型接进`真实业务`里”，做出能解决问题的 `AI 应用`。

这也是我做这个项目的原因：把我自己学习 `AI Agent 开发`过程中踩过的坑、筛过的资料、整理过的路线和面试内容，尽可能`沉淀下来`，让想入局的朋友`少走一点弯路`。




## 2. 项目简介

`AI Agent 开发`，别名：`AI 应用开发`、`大模型应用开发`、`智能体应用开发`。

简单来说，它关注的不是“从 0 训练一个大模型”，而是如何基于`现有大模型能力`，结合`业务系统`、`知识库`、`工具调用`、`工作流`、`记忆`，让 AI 真正完成任务。

这个网站想解决几个很现实的问题：

- `学习路线太乱`：网上资料很多，但新手很难判断先学什么、后学什么；
- `优质资料分散`：文档、视频、开源项目、教程文章到处都是，找资料本身就很耗时间；
- `面试内容不系统`：AI 应用开发相关岗位越来越多，但面试题、面经和实战问题还比较分散；

所以本项目会围绕“`学习路线 + 面试题库 + AI 智能刷题 + 社区共建`”，希望把它做成 AI Agent 开发领域里，对普通开发者最友好、最实用的`一站式学习网站`。




## 3.项目特点

1. `持续学习，持续更新。`  AI 方向变化太快，内容和系统功能都不能停在某个时间点，我会尽量保持跟进和维护。

2. `认真筛选，不堆垃圾资料。`  这里不会为了显得内容很多而随便堆资料，我会优先整理真正适合学习的内容。

3. `听取建议，快速迭代。`  如果你觉得路线不合理、资料过时、题目有问题、功能不好用，都欢迎直接提出来，我会根据反馈持续改进。

4. `保持节奏。`  我会尽量做到每天维护代码仓库，每周进行一次上线发布。

   


## 4. 功能介绍

### 功能一：学习路线和资料

如果你刚开始接触 `AI Agent 开发`，最容易卡住的问题通常不是学不会，而是`不知道该从哪里开始`。

`学习路线`会按照顺序，尽量把每个阶段需要掌握的内容讲清楚。

每个知识点都会尽量描述：

- 这个技术是`干什么的`；
- 推荐看哪些`资料`；




### 功能二：AI 智能刷题

传统刷题很容易变成`机械重复`：做对了就过，做错了看一眼答案，然后下次可能还是忘。

`AI 智能刷题`做到了：

- 根据权重智能筛选出题：`题目重要程度`、`用户历史最高分数`、`历史刷过次数`。
- `AI大模型智能评分`，给出命中点、不足之处、改进建议。
- 评分之后可以和`AI持续探讨`，直到彻底弄懂题目。
- 通过刷题得经验升级，`正反馈激励机制`把握学习进度。




### 功能三：热门面经

也有很多人更习惯先通过`文档学习`，再进行`刷题`。

本功能汇集了所有`热门面经`，按知识点分类展示，AI智能刷题的题目也是从此抽取。




### 功能四：评论建议区

这个项目不想只做为我的私人学习网站，更希望它能慢慢变成一个大家一起`共建的学习站点`。

你可以在系统里留下`评论`、`提出建议`，也可以告诉我哪些资料更好、哪些题目需要补充、哪些功能更值得优先做。

后续我会优先处理`点赞较多`的建议。

对于持续提出有效建议并被采纳的朋友，也会考虑在项目中展示`贡献`和`答谢名单`。

目前最想搞好的是：`AI智能刷题功能和UI样式`，急求这两块的体验建议。



## 5.后续想法
