# 大数据平台研发工程师

## 岗位职责

- 参与大数据平台产品层核心功能的设计、开发与迭代优化，保障平台产品的稳定性、高效性和易用性。
- 深入理解底层大数据组件的工作原理，负责平台与 Hive、Spark、Flink、ES 等组件的后端集成、调优与问题排查。
- 协同产品、测试及业务团队，梳理业务需求并转化为技术实现，推动大数据平台在业务场景中的落地应用。
- 关注大数据与 AI 领域前沿技术动态，参与以大数据平台为底座的 AI 应用开发和效能提升工作。

## 任职要求

### 1. 基本要求

- 本科及以上学历，计算机相关专业，3 年及以上大数据平台后端研发相关工作经验。
- 具备扎实的 Java 后端开发基础，熟悉分布式系统设计原理和大数据处理流程。
- 有 Hadoop、Hive、Flink、DataX、ES、Doris、Spark 等大数据组件的使用和后端集成经验。
- 熟练使用主流 AI Coding 工具，同时具备一定的 AI Agent 开发流程和调优经验。
- 具备良好的编码习惯和文档编写能力，拥有较强的问题分析与解决能力。
- 具备优秀的团队协作精神、沟通能力和抗压能力，能积极应对项目中的各类挑战。

### 2. 核心技术要求

- 熟练掌握大数据平台产品层的后端开发技术，有过大数据平台核心模块，如数据集成、离线数据开发、实时数据开发、数据服务等模块的后端开发经验。
- 熟悉底层大数据组件，包括但不限于 Hadoop、Hive、Spark、Flink、Doris、ES 等，具备相关组件的后端集成与调优实战经验。
- 掌握常用的数据库技术，如 MySQL 等，具备库表结构设计与 SQL 调优能力；熟悉 Kafka 消息队列。
- 熟悉微服务架构设计理念，具备 Spring、Dubbo 等微服务框架开发经验。

### 3. 优先条件

- 有基于大数据基础设施的 AI Agent 开发经验者优先。
- 有大规模大数据平台研发、运维及性能优化经验者优先。
- 有前后端全栈开发经验者优先。
